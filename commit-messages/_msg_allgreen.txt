## 🔴 根因一：`subprocess.run(text=True)` 缺 `encoding=`（**11 处**，系统性）
4 个失败（`test_cad_studio_cli` ×3 + `test_dfm_review` ×1）**同源**：
```
子进程输出 **UTF-8 中文**，父进程用 `locale.getpreferredencoding()`（本机 **GBK**）去解
⇒ UnicodeDecodeError ⇒ completed.stdout = **None** ⇒ json.loads(None) 抛 TypeError
```
**⇒ 给 11 处补 `encoding="utf-8", errors="replace"`**（6 个文件）。
⚠ **第一次扫描报了 23 处，是**假阳性**** —— 我按「第一个 `)`」截断调用段，把本来就有 `encoding=`
的多行调用误判了。**⇒ 改用**括号配对**切分 ⇒ 真值 11 处。**

## 🔴 根因二：`Path("D:")` **不是盘根** —— 一个**真实功能 bug**（第 5 个失败）
```
scripts/cad_installation.py: root = Path(drive)          # drive = "D:" / "E:"
⇒ Path("D:") / "AutoCAD 2024" / "acad.exe"  =  'D:AutoCAD 2024\acad.exe'  ← **缺反斜杠！**
⇒ **D:/E: 盘上的 AutoCAD / SolidWorks 一直发现不了**（不只是测试问题）
⇒ 修法: Path(drive + "/")  ⇒ 'D:\AutoCAD 2024\acad.exe'
```
**★ 这个 bug 是那个测试**尽职抓到的** —— 它注入的 `exists` 只认精确字符串，
于是把「路径拼错」暴露成了断言失败。**（测试做得对，代码错了。）**

## ⚠ 顺带踩到并记下的一处
