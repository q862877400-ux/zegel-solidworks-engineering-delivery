## 读示例直接改掉的两处实现

1) create_swept_flange 属性装配与官方不符
   官方 Create_Swept_Flange_Example_VBNET 第 37-88 行:
     InsertSheetMetalBaseFlange2 -> 选轮廓 -> 选路径 -> CreateDefinition
     -> 设 14 个属性 -> CreateFeature
   · **官方根本不设 Thickness**(走 UseMaterialSheetMetalParameters 从基体法兰继承)
     我初版设了 => 删掉, 改为 thickness=None 表示继承
   · 我漏了 7 个属性 => 补 FlangePosition / FlattenAlongPath /
     TrimSideBends / UseDefaultBendRelief / UseGaugeTable /
     UseMaterialSheetMetalParameters / OverrideDefaultSheetMetalParameters
   · 我多设了 ReliefRatio => 删(官方走 UseDefaultBendRelief=True)
   · 官方这条路径**不**调 AccessSelections/ReleaseSelectionAccess => 我也不调
   · 新增 SWS_SWEPT_FLANGE_POSITIONS 枚举(1/2/3, 取自 swSweptFlangePositionTypes_e)
   · start_offset 的下界从 >0 放宽到 >=0(官方示例里 StartOffset=0)

2) sw_surface.py 的路线表述过于绝对, 已更正
   读 Create_Radiate_Surface / Create_Planar_Surface_Feature /
   Create_Trimmed_Surface_Feature / Access_Selections 四个官方示例后发现:
   曲面域有**两条互补路线**
     路线 A 脚本造几何曲面  = IModeler.Create*Surface (本模块实现)
     路线 B 界面创建+脚本参数化 = GetDefinition() + AccessSelections
   Radiate/Planar/Extend/Knit/Fill **没有脚本创建入口**(官方一律界面建好
   脚本再 GetDefinition 取回)。唯一例外是 IFeatureManager.PostTrimSurface(Boolean)
   —— 扫 263 个方法, 曲面类 Post* 只有这一个。
   ⇒ 早前「无接口返回 ISurface*FeatureData ⇒ 不是创建入口」结论对,
     但由此推断「官方不用它们」是错的, 已在 sw_surface.py 与使用指南中更正。
