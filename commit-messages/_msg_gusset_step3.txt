## ① 官方把 gusset 的创建写成 **4 步**，而模块**整步跳过了第 3 步**
`C:\swapi\types\ISMGussetFeatureData\_overview.md` 的 **Remarks**：
```
1. Call IFeatureManager::CreateDefinition
2. **Pre-select** faces/lines/edges/vertices/points（legs）
3. **Specify ISMGussetFeatureData::ProfileDimensionScheme and modify other properties**  ← ★
4. Call IFeatureManager::CreateFeature
```
**模块的 `_apply` 只设了 4 个**尺寸**属性，而第 3 步的**头一句** `ProfileDimensionScheme`
**从未设过**。**官方属性页还明写**：
* `UseAngleDimForProfile`：「**valid only if `ProfileDimensionScheme` is set to 1**」
  ⇒ **不设 scheme 就设角度维，那个属性可能根本不生效**
* `UseOffset`：「**After setting this property to true, set the offset distance.**
  **If a reference point is not set, the offset is applied to an assumed reference point.**」
  + Remarks 第 2 步：「**If you do not pre-select any of these entities, then you must
  set `UseOffset` to true**」⇒ 模块**不预选参照点** ⇒ **必须**置 true

**⇒ 已补上 `ProfileDimensionScheme = 1`（`swSheetMetalGussetProfileDimType_ProfileDimensions`，
数值取自官方枚举页）、`UseOffset = True`、`OffsetDistance = 0.0`。**
