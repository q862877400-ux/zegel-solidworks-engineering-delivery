## 两个真因（都不是「换个写法试试」试出来的）

### 真因 1 · 材料库名是**显示名**，不是文件名
VB6 类型库 CHM（`SldWorks~PartDoc~SetMaterialPropertyName2.html`）给出三参数：
`(ConfigName, Database, Name)` —— 我的形式本来就对，**错在 `Database` 的值**：
    库名 "SOLIDWORKS Materials" + 材料 "Plain Carbon Steel" → 回读 MaterialIdName = ''  ✗
    库名 "SOLIDWORKS Materials" + 材料 "AISI 1020"          → 回读
        'solidworks materials|AISI 1020|2'                                            ✓
⇒ **`"Plain Carbon Steel"` 不在该库里**；且库名必须大写带空格，不能照 `.sldmat` 文件名小写。
⇒ 另：直接写 `set_MaterialIdName` 只赋**标签**、不加载材料属性 ⇒ 求解仍报 19。**不要走那条路。**

### 真因 2 · 选面用「面上的点」，不是原点
既有 `sw_part._select_by_id(ext, "", "FACE", …)` 走 `SelectByID2("", "FACE", 0, 0, 0, …)`
—— 原点在实体**内部、不在任何面上** ⇒ 一个面都没选中 ⇒ `DispArray` 为空
⇒ Simulation 弹「**未定义载荷或规定的位移**」并显示失败。真机对比：
    SelectByID2("", "FACE", 0, 0, 0,     …) → 选区计数 **0**
    SelectByID2("", "FACE", 0, 0, -0.02, …) → 选区计数 **1**  ✓

## 第三个「返回码撒谎」
夹具/载荷未定义时 `RunAnalysis` **仍返回 0**（而研究实际失败）。
⇒ **判据必须是 `study.Results` 非空 + 图数**，不是返回码。已写进 `run_analysis` 的来源块。
