## ① 新增 `scripts/sw_geometry_selectors.py`（B 类基础设施）
`sw_surface` 里 4 个**运行期可达**的创建器都收 `Object` 型的点/向量
（`CreateCylindricalSurface(origin, axis, r)` / `Spherical(center, r)` /
`Conical(origin, axis, half_angle, r)` / `Toroidal(origin, axis, center, R, r)`）
⇒ 直接暴露会**违规则 3**（禁裸坐标）⇒ 加一层**声明式解析**：

| 类别 | 合法选择器 | 说明 |
|---|---|---|
| **点** | `origin` / `bbox:min` / `bbox:max` / `bbox:center` / `centroid` | **全部从模型派生** |
| **方向** | `+x` / `-x` / `+y` / `-y` / `+z` / `-z` | **命名轴**，与 `sw_simulation.FACE_SELECTORS` **同一套命名** |

**⚠⚠ 规则 3 的红线**：本模块**绝不接受裸坐标**。错误信息里明写
「需要任意坐标时，请先建参照几何再选它」。**非法选择器一律报错，不静默返回原点。**

**⇒ 真机实测 12/12 通过**（`probe_geometry_selectors_e2e.py`）：
`bbox:min (-0.05,-0.03,-0.02)` / `bbox:max (0.05,0.03,0.0)` / `centroid` 正确。

## ⑤ ⚠ 一个新发现（如实记，未定性）
真机建曲面时：**`spherical` / `toroidal` 返回非 None（真建出来），
`cylindrical` / `conical` 返回 `None`**。
**⚠ 而 `sw_surface` 的包装器**不检查返回值** ⇒ 这是**静默失败**类。**

**⇒ 未定性**：可能与参数（origin 落在体内部 / axis 与半径的组合）有关，**不猜。**
