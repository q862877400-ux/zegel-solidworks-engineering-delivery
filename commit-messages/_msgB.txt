## ⚑ 本轮最重要的一件事：一次误判的纠正
此前交付的文档写着「cosworks 册是空壳、27 个 Add* 方法签名不可得」。
**该判断是错的。**

`SWhelp\cosworks\ICWLoadsAndRestraintsManager~<成员>.html` 单页近 1MB，
含 `Syntax` / `Parameters` / `Return Value` / `Remarks` 全文
（`AddBearingLoad.html` 实测 967,851 字节）。
它看起来是空壳，是因为**正文以 JSON 转义（`\u003c` = `<`）嵌在 script 标签里**，
按 `<script>` 抓、再按 `<[^>]+>` 去标签，自然只留下真 HTML 的导航栏。
⇒ 是**解码路径错了**，不是**内容缺失**。

AGENTS.md §四.1 其实早就写了「cosworks 册薄得刚刚好、正中载荷那个坑」，
我却只抽查 1 个页面就下了全局结论。**该相信的原文我跳过了。**
