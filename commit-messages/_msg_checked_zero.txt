fix(Spec Kit 008): `checked == 0` 的 SKIP 语义 —— 复现并修掉**轮 55 那个误 SKIP**；并修一个**假用例**

## 起因：轮 83 自己记下的最后一处未查证
`007-skip-semantics` 系统排查 SKIP 语义时，如实记下 `check_signature_audit_freshness` 的第三处：
```
if checked == 0:
    print("**SKIP** —— 一个模块都没能实跑（便携性守卫）")
    return 0
```
⚠ 而 **轮 55 首跑就撞上过这个形态**：`resolve_module` 解析写法不对 ⇒ **6/6 全报「跑不了」⇒ 误 SKIP**
（当时靠人发现才修，注释还留在 `resolve_module` 的 docstring 里）。本特性**去查证并修掉**。

## 为什么它**必然**是 FAIL（论证，不是猜）
```
① 能走到 checked == 0 ⇒ `refs` 必然非空（上游已把「拿不到反射」那条 SKIP 掉）
② 表里的模块是**本仓库自己的 `.py`**（scripts/*.py、subskills/**/*.py）
⇒ ③ 反射在、却一个都解析不出 ⇒ 只可能是**解析坏了 / 仓库残缺** —— **故障，不是便携性**
```

## ★ 先复现，再改（`tools/probe_checked_zero_skip.py`）
`--repo <空临时目录>` + `--raw <真反射>` ⇒ 逼出目标路径（**不改任何仓库文件**）：
```
修前: 反射文件 **13** 份 · ⚠ 6 个模块跑不了 · **SKIP** ⇒ **exit=0**（全绿）
      —— **与轮 55 的误 SKIP 形态一模一样**
修后: [FAIL] 反射转储**在**（13 份），但表里 **6** 个模块**一个都解析不出来** ⇒ **exit=1**
便携性: --raw <不存在> ⇒ 仍 `**SKIP** —— 拿不到 iface_*.txt`，exit 0（**未受损**）
```

## ★★ 顺带修掉一个**假用例**（它比没有用例更糟）
`tools/probe_skip_semantics.py`（`007` 的交付物）里有个用例「把逐模块表用正则删掉看门禁是否红」——
轮 84 回看发现 **那条正则根本没匹配上** ⇒ 产出的"坏文档"**仍带完整的表** ⇒ 门禁照常 `[PASS]`，
⚠ **而我在轮 83 把它当成了"修好了"的证据**。
⇒ 改成**造一份只有标题、不含表的文档**（那才是「文档在、表读不出」的定义）⇒ 实测 `exit=1`，用例才成立。

★ **教训：假用例比没有用例更糟** —— 它给出一份**看起来验过的**证据。
⚠ 与已知事实 62「门禁写了不等于有效」**同族**，只是发生在**测试**而非门禁上。
