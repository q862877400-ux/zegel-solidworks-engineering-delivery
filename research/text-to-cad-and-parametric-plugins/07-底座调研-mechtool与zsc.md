# 底座调研：mechtool.cn 与 zsc 机械设计实践教程

调研日期 2026-11-04 · 配套 `triage.jsonl`（53 项分流表）

---

## 0. 结论

这两个站**不是同一类东西**，但正好互补，合起来能当「分系统该做哪些族」的地图：

| 站 | 是什么 | 给我们什么 |
|---|---|---|
| **mechtool.cn** | 机械设计**数据与工具**站：标准件数据、25 个在线计算/选型工具、CAD 资源（含 MISUMI / SMC / CHELIC / SEW / 东方马达的 3D 选型软件）、机械书籍、图纸模型 | **行业自己认为"哪些要算、哪些要选"的清单**——这直接就是分流依据 |
| **zsc.github.io/mechanic_design** | 《机械设计实践教程》**18 章**，面向资深程序员与 AI 科学家，以经验法则为主 | **主题覆盖地图**——跨行人学机械要碰哪些东西 |

**一句话**：一个告诉我们**行业怎么分工**，一个告诉我们**覆盖面有多宽**。

**但两者都不能直接当数据源**：
- mechtool 的数字是**二手整理**（它自己写「如遇数据资源缺少或数据错误请反馈」），落地必须回到标准原文；
- zsc 是 **CC BY-SA 4.0**——**传染性许可**，只能当主题索引，文本不能抄进项目。

## 1. mechtool.cn：25 个计算工具，就是行业的"该算什么"清单

它左侧导航的「常用设计计算工具」是这批（原文逐条）：

| 类别 | 工具 |
|---|---|
| 连接 | 螺栓连接设计校核 · 键连接设计校核 |
| 支承 | 滚动轴承设计与查询 · 直线轴承选型 · 直线导轨选型 |
| 传动 | 渐开线圆柱齿轮传动设计 · 普通圆柱蜗杆传动设计 · 带传动设计 · 链传动设计 · 倍速滚子链选型 · 滚珠丝杆副设计计算 · 螺旋传动设计 · 凸轮分度(割)器选型 |
| 弹性 | 弹簧设计 |
| 轴系 | 轴设计计算 |
| 密封 | 密封系统设计 |
| 流体 | 液压传动系统计算 · 气压传动系统计算 · 水系统设计计算 · 油压缓冲器选型 |
| 电气 | 电气工程计算 |
| 精度 | 公差与配合查询 · 形状与位置公差查询 |
| 动力 | 电动机(减速机)选型计算 |

**读这张表要注意一件事**：里面**没有"齿轮生成器"，只有"齿轮传动设计"**。
行业把齿轮当**算**的事，把"画出来"当成插件（GearTrax）的活。**这正好解释了为什么我们第一个族选齿轮**——它是"算"与"画"之间那段没人做好的缝。

另外它收录了 **MISUMI / SMC / CHELIC / SEW / 东方马达的 3D 选型软件**——这就是「买」这条路的工具入口，和项目已有的 `scripts/sw_misumi.py` 是同一件事。

## 3. 分流判据：一句话

> **这个零件的尺寸，能不能被一张表穷举？**
> **能 → 买**（标准件，几何无自由度）
> **不能，但能由公式唯一算出 → 造**（生成器）
> **两者都不行 → 记录，放一放**（非标手画）

| 桶 | 判据补充 | 处理 |
|---|---|---|
| **买** | 厂商目录定义了尺寸与额定值；自己算几何是浪费，自己编数据是危险 | 接**选型器**：去哪下载 + 怎么选 |
| **造（有代码）** | 几何由参数 + 公式唯一决定，且已有开源实现 | **接入生成器** |
| **造（无代码）** | 几何非标/多解/靠经验，或没有成熟实现 | **登记，放一放** |
| **非零件** | 是判据、工艺或数据，不是几何 | 作为判据层，不做族 |

**还有一类必须拆开**：同一个东西的两半归属不同——
- **键**：键买、**键槽**造
- **同步带**：带买、**带轮**造
- **滚子链**：链买、**链轮**造
- **密封件**：O 圈买、**沟槽**造

**注意「买」比「造」多近一倍**——这本身是个结论：**机械行业里大部分"零件"其实不设计，只是选**。我们如果只盯着"生成器"，会做错一半的活。

## 5. 放一放清单（6 项，已登记不丢）

| 件 | 为什么放 | 行业现在怎么做 |
|---|---|---|
| **凸轮** | 运动规律→轮廓，**没有成熟开源库**（商业 CamTrax64 一家） | 买成品分度器，非标靠专用软件或手画 |
| **连杆机构** | 综合是多解非线性问题，**PMKS+/Linkage 都只做分析不做综合** | 图解 + 经验 + 商业软件（SAM/MechGen 已停售） |
| **非标支架/连接件** | 完全非标，无参数可推导 | **手画** |
| **壳体/机箱** | 同上 | 手画 |
| **夹具/工装** | 同上 | 手画 |
| **行星轮系** | 装配级约束求解，属**下一层** | 商业软件或手算 |

**这六项的共同点**：它们不是"难"，是**没有可枚举的参数域**——所以既不能买、也没法用生成器。**记录在这里，是为了以后不必再讨论一次"要不要做"。**

## 6. 三条结论

### ① 「底座」这个判断成立，但要拆成两半用
- **mechtool 当"买/算"的行业清单**——它的 25 个工具就是分流依据，比我们自己拍的准；
- **zsc 当"覆盖面"地图**——18 章告诉我们跨行人要碰哪些东西；
- **两者都不当数据源**（二手 + CC BY-SA）。

### ② 「买」这条路比想象的重要
53 项里 25 项是买。项目已有 `sw_misumi.py` 与 `sw_toolbox_index.py`（1844 件/19 标准），**这条路的基建已经有一半**，缺的是「选型 → 取件 → 插入 → 回读尺寸」的闭环。

### ③ 第一个族选齿轮是对的
mechtool 只有"齿轮传动设计"（算），没有生成（画）；GearTrax 有生成但没有强度。**这条缝就是我们要站的位置**——而它已经被 `sw_gear.py`（stitched）+ `cq_gears`（Apache-2.0）验证过可行。
