## ★ 问题 3：**哪些操作必须排在最后？**（★ 最容易做反 ✓）

```
★ 我接下来要做的这个特征，会不会【占用/依赖】某块几何？
★ 如果会 ⇒ 它必须排在"切掉那块几何"之前 ✗
★ 我是不是打算【先切、后加】？⇒ 那大概率错了 ✗
```
★★ **两条已确认的纪律**（★ `P16` [02:46]–[02:57] · [07:35]–[07:40] ✓）：
```
★ ① 【切要留到最后】—— 作者原话：「我们在这里**先不要急着切**」「我们**放到最后**以防」
     ★ 理由：★ 后面新建的草图/特征会【**占用已经被切掉的那部分**】✗
★ ② 【孔要放在后面打】—— 作者原话：「我们是**忘记打孔了**」「**也不是忘记打孔**」
     ★「是**要放在后面打的**」✓
```
★★ **归纳出的规则**：★★ **会"占用几何"的操作排在后面；"减掉几何"的操作排在最后** ✓

## ★ 问题 4：**我用的这个命令，吃不吃圆弧 / 要不要相切？**

```
★ 这个命令【能】用圆弧吗？（★ 不是所有命令都吃 ✗）
★ 如果用圆弧，必须【相切】吗？
★ 这个命令点选时，有【顺序】要求吗？有【上/下边线】要求吗？
```
★★ **已裁决的一张表**（★ 依据 `P26`/`P28`/`P30` 的三次实测 ✓）：

| ★ 命令 | ★ 吃圆弧？ | ★ 要不要相切 | ★ 顺序要求 |
|---|---|---|---|
| ★ **转折** | ★★ **不吃** ✗（★ `P28` 三次实测 ✓）| ★ — | ★ — |
| ★ **绘制的折弯** | ★★ **不吃** ✗（★ `P29` 作者总结 ✓）| ★ — | ★ — |
| ★ **斜接法兰** | ★★ **吃** ✓（★ `P26` 三次实测 ✓）| ★ **相切可、不相切也可**（★ 靠**自动圆角** ✓）| ★★ **必须按顺序** ✗（★ 有起始点/结束点 ✓）|
| ★ **边线法兰** | ★ 未讲 ✗ | ★ — | ★★ **可不按顺序** ✓ · 上下边都能点 ✓ |
| ★ **扫描法兰** | ★ 可用 ✓ | ★★ **不用相切圆角** ✓（★ `P30` ✓）| ★★ **必须按顺序** ✗ · **只能上边线** ✗ |

★★ **注意**：★ `P29` 的「折弯也不能用弧线」这半句**已判定为转写失真** ✗ ——
