# 088 · 「一次性查」的盲区用**负例**证实；轮询成为默认（一处改动覆盖 34 个调用点）

**Status**: Implemented（轮 168）

## 一、动机
轮 167 把 `residual_dialogs` 的默认值改成了轮询，但★「**改了**」不等于「**改对了**」（事实 62）。
⇒ 本轮**制造出那个盲区并当场对比两种查法**。

## 二、★★★ 证伪实验（`tools/verify_modal_polling_catches_async_dialog.py`）
```
② **只查一次**（紧接触发 COM 调用）⇒ **0** 个框   ← ★★★ **漏了**（= 改之前 34 个调用点的形态）
③ **轮询 1.5 秒**                    ⇒ **1** 个框   ← ★★★ **抓到了**
④ 点掉 1 个 · 后台退出码 0
⇒ ★ 同一个弹窗、同一时刻附近，两种查法给出**相反结论**
```

## 三、⚠⚠ 实验第一版**设计错了**（如实记）
```
我把「一次性」写成了「**1.2 秒内循环查 19 次**」⇒ **那本身就是轮询**
⇒ 命中 14/19 ⇒ **没造出盲区**
⇒ ★ 我按判据**如实报了「本实验没造出盲区（不是"修好了"）」**，然后才改成「**真的只查一次**」
⇒ ★ 教训：**做「A 会不会漏」的实验时，对照组 A 必须真的是 A。**
   「重复查很多次」不是「只查一次」——混起来会让实验**自动通过**（假阴性）。
```

## 四、★ 落地（一处改动覆盖 34 个调用点）
```
residual_dialogs(pid=None, *, settle_seconds=1.0, poll_ms=200)
  · 默认 settle_seconds=1.0 ⇒ **轮询**（34 个调用点全部受益，**不必改 34 个文件**）
  · 默认 pid=None          ⇒ **自己从 COM 派生**（零硬编码）
  · 要「只看此刻一眼」时显式传 settle_seconds=0.0
  · 取**整个窗口期内见过的最大值**（弹窗可能已被别人点掉，但「**弹过**」这个事实更重要）
```
