## 四、★★★ 一条可复用的教训：**重命名式迁移 = 调用 + 所有导入点 + 所有桩**
```
给一个**被广泛导入**的名字做重命名 ⇒ 你同时改了：
  ① 所有**调用点**；② 所有**导入行**（单行/多行/try-except 两份）；
  ③ 所有**测试桩**（三种形态：`X.f = g` / `SimpleNamespace(...)` / **记录式 lambda**）
⇒ 本轮 ④ 类里我漏了 ②（except 回退那份）与 ③（记录式 lambda），各红一次。
⇒ ★ **必须把"调用"与"导入"当成一件事来验**（本轮的判据就是这么来的）。
```
