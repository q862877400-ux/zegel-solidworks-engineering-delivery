**[00:35]** 逐字：「这样我们就**不能直接用回转的方式来构建它**」
**[00:35]** 逐字：「**必须要一层一层建**」

**★★★ 判据（★ 本集最值钱的一条 ✓）**：
```
★ 判"能不能回转"的方法：★ 看【截面是不是圆】
   ★ 有【不是圆】的段 ⇒ ★★ 不能用回转 ✗ ⇒ 【一层一层建】（逐段草图 + 拉伸）✓
   ★ 全是圆           ⇒ ★ 可以回转 ✓
```
★★ **为什么**：★ 回转是**绕轴扫一圈** ✓ ⇒ ★ 它要求**所有截面都是圆** ✗ —— ★ 只要有一段**非圆**（★ 如六方、扁方 ✓）
★ 整个实体就**转不出来** ✓
