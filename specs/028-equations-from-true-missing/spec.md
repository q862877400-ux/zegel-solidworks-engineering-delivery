# 028 · 从「真缺」再补一条：方程式

**Status**: Implemented（轮 109）

## 背景
`023`/`024` 已从「真缺」档补了螺旋线、草图倒角/镜像。本轮接着补 **`equation`（方程式）**
（`022` 的核样确认它确实没有实现）。

## 做法（铁律 1 + 4）
* **来源**：`本项目自建` —— 依据**官方 API**（合法来源）；
* **签名两源互证**：
  * 出厂反射：`IEquationMgr EquationMgr GetEquationMgr()`（在 `IModelDoc2` 上，**0 参**）、
    `Int32 Add2(Int32, String, Boolean)`、`Int32 GetCount()`、`Int32 Delete(Int32)`、`Int32 EvaluateAll()`
  * `C:\swapi\types\IEquationMgr\*.md`：同 5 条，参数名齐全
  * ⇒ **两源逐条一致**，无需类型库裁决。

## ★ 两处要留神的地方
### ① `Add` 已废弃 ⇒ 走 **`Add2`**
官方 md 明写 `IEquationMgr.Add` 是 **`Obsolete. Superseded by IEquationMgr::Add2.`**
（`Add` 比 `Add2` 少一个 `Solve` 参数）⇒ 与 `024` 的 `SketchChamfer` 同类处置。

### ② ⚠⚠ **`-1` 有两种语义，必须分清**
```
作为入参：  Index = -1   ⇒ 追加到末尾（官方语义）
作为返回：  Add2 返回 -1 ⇒ **失败**
```
★ 若不区分，**失败会被当成"插到了末尾"** ⇒ 本模块对返回 `-1` **抛异常**，
并在消息里点出官方 Remarks 里最常见的失败原因（维度名没带双引号）。

## 判据
| ID | 判据 |
|---|---|
| SC-2401 | ★ 走 **`Add2`** 不走已废弃的 `Add`（测试钉住源码里不出现 `"Add",`）|
| SC-2402 | ★ **`-1` 的两种语义分开**：入参 `-1` 合法，返回 `-1` 抛异常 |
| SC-2403 | 三个实参顺序与类型照官方 `(Index, Equation, Solve)` |
| SC-2404 | 空串**提前拦下**（不白跑一次 COM）|
| SC-2405 | 删/求解失败（`-1` / `None`）也抛，**不静默** |
| SC-2406 | 拿不到管理器时抛**带成员名**的错 |
| SC-2407 | 来源块写明等级 **`stitched`** 且**无本机运行证据** |
| SC-2408 | `capabilities.yaml` 新增 `equations`（`stitched`），33 → **34** 条 |
| SC-2409 | 门禁 + 回归不退化（回归 **1084 passed**）|

## ⚠ 明确记下的限度
* **等级 `stitched`** —— 只有静态证据，**本机从未读写过方程式**；
* **不做方程式字符串格式校验**（官方没给可校验的语法，本模块只挡空串）；
* 官方 Remarks 提到「直接编辑装配体零部件的模型需在上下文中编辑」—— **未处理**；
* `IEquationMgr` 另有 **11 属性 + 14 方法**，**未逐一实现**；
* 本轮**主动不做真机测试**（轮 98 的模态框教训）。
