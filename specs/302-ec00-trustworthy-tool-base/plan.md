## 一、★★★★ 技术判断（★ 逐字承 P0 PLAN §1）

★★ **不要新建第二套**工具注册/选择/锁/证据系统。

★★★★ **把四件事分开**（★ 这是本特性的核心设计）：

| ★ 面 | ★ 含义 | ★ 例 |
|---|---|---|
| ★ **API 返回** | ★ COM 回了什么 | ★ `True` / `None` |
| ★ **执行状态** | ★ 调用走完了没 | ★ `returned` / `timeout` / `uncertain` |
| ★ **实际效果** | ★ 模型**真的**变了没 | ★ `pass` / `fail` / `unknown` |
| ★ **验证等级** | ★ 我们有多少证据 | ★ `offline` / `runtime` / `product` |

★★★ **⇒ 单 `success` 字段容纳不了这些情况**：★ `true` **可以伴随** effect fail；★ 异常**可以伴随**实际已修改；
★ offline pass **可以伴随** runtime not_run。

## 六、★★★★ 核心算法与失败处理（★ 逐字承 P0 PLAN §5）

### 6.1 ★★ 单位（US1）

1. ★ 查 ToolSpec 字段的物理量、公开单位、规范化单位、COM 边界单位及历史默认。
2. ★ 拒绝未知单位、错误量纲、非有限值及不符合域约束的值。
3. ★ 用受测映射 `normalized = supplied × scale`；★ **偏置单位如温度独立定义，不混用乘法**。
4. ★ 规范化结果用**不同结构包装**，避免作为原始输入再次进入转换。★★ **不能只靠字段名以 `_mm` 结尾推断**。
5. ★ 到**官方确认的 COM 接口边界**转换**一次**，记录目标单位和实际参数。
6. ★ 输出**必须标单位**；★ 尺寸回读按同样规则规范化后比较。

★★ **同单位对照不只测 10 mm** ⇒ ★ 还要测**小值、大值、允许零值/负值、重复规范化、旧接口混合调用**。
★★★ **长度负值是否允许由字段语义决定，不能全局禁止或允许**。

### 6.2 ★★ 文档身份与版本（US3）

- ★ 模型身份至少区分**会话内文档、配置、保存身份**；★★ **未保存文档不能把空路径当全局唯一 ID**。
- ★ 请求记录**预期模型版本**。★ 执行前检查，不一致则**拒绝或重新计划**；★★ **不能执行后补写版本来合理化**。
- ★★ **文件哈希只能描述保存字节，不能代表尚未保存的内存模型**。★ 现有内存指纹能否检测尺寸/特征/配置变化**需先研究**。
- ★ 若无可靠内存变更检测 ⇒ ★ **保守策略**：受控节点、禁止未确认外部编辑、明确保存检查点；★ 无法确认时 `unknown`，★ **不声称强一致**。
- ★ **完整作业租约/围栏与全链批准版本绑定由 EC04 实现**；★ EC00 只定义**兼容字段**和本地边界。

### 6.3 ★★ 引用解析（US3）

```text
持久引用恢复
  → 类型 / 所属文档 / 配置检查
  → 语义锚点核验
  → 几何签名与容差比对
  → 唯一候选才返回
  → 0 候选 / 多候选：拒绝并记录
```

★★ **重建/特征替换可能改变拓扑**。★ 持久引用字节相同**不等于**一切语义稳定；★★ **几何接近也不能自动确认是原对象**。
★ 只记录定位证据，★ **不猜测 API 返回包装**。

### 6.4 ★★ 关系效果（US2）

- ★ 前态记录实体类型/身份、已有关系、关键坐标或曲率度量、**预期自由度**。
- ★ 按**已核验**官方签名和调用序提交关系。
- ★ 后态回读关系与义务。★★ **关系存在但几何不满足**、★ **或几何巧合满足但未建立应持久的关系**，★ **均不能当作完整成功**。
- ★ 数值判据用 `abs(error) ≤ abs_tol + rel_tol × scale`；★ 容差与尺度定义随关系类型冻结；★★ **不能任意放宽到刚好通过**。
- ★ 相切要核验**相关方向/接触位置的语义**；★ 重合与相等也要**区分对象类型**，★ **不能统一比较一个坐标**。
- ★ **欠约束不天然失败，过约束不天然由加更多关系解决**。★ **预期自由度必须明确**。
- ★ 无可信关系回读时返回 `unknown`；★ 安排限定探针，★★ **不将「看截图像对」升级成机器通过**。

### 6.5 ★★ 效果状态机（US4）

```text
validated → context_checked → executing
  ├─ known no execution → rejected / failed
  ├─ returned → inspecting → pass / fail / unknown
  └─ timeout / ambiguous COM error → uncertain
                                  └─ inspect / recover，不能直接 retry
```

★★★ **「没有完成返回」不等于「没有修改」**。★ 异步护栏退出、COM 服务错误和读取失败**都可能产生不确定状态**。
★ 只有**操作可证实未执行、已满足或可受控补偿**时，才能选择下一步。

### 6.6 ★★ 恢复与写入保护（US4）

- ★ **不对所有动作提供通用 rollback**；★ COM 操作**不是数据库事务**。
- ★ 使用批准的**自有检查点、前向补偿或停止人工处理**；★ 逐类定义。
- ★ **保存重开只操作自有样例**；★★ **用户未保存文档不在自动关闭/重启范围**。
- ★ 特征创建超时：★ 先检查是否存在**预期效果及多余实体**；★ 无法判断则**停止**。
- ★ 旧入口兼容时**不改变恢复语义**，★★ **更不能把 `unknown` 压回 `true`**。
