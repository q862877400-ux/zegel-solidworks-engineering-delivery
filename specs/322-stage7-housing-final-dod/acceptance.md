## §5 ★★ 本阶段最关键的一条：**证据非循环**（SC-010）

**外部方案 §5 R7 ④ 逐字**：

> 「替换一份证据为『**读取台账并断言 `verified`**』、移除必需图纸、
> 替换旧版本产物、隐藏一次人工接管，交付完整性与证据检查必须分别失败」

**★★ 为什么这条最重要**：

```
台账（capabilities.yaml 的 level）是**我们自己写的**
⇒ ★ 拿它证明自己 = **循环论证**
⇒ ★ 产品级证据必须是**外部可核**的（真机回读 / 文件 / 尺寸）
```

**★ 实测**：`H.Evidence(kind=EV_LEDGER, path="capabilities.yaml")`
⇒ `evidence_is_noncircular()` 回 **`ok=False`**，并**具名报出**：
```
[{"path": "capabilities.yaml", "why": "★ 台账级证据不能当产品级"}]
```

**★ 另加**：`CIRCULAR_PATTERNS` 里逐字列了 6 种循环形态
（含「读取台账」「断言 verified」「台账等级」），★ **连文本形态都查**。
