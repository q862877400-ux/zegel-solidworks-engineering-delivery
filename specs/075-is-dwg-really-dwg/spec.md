# 075 · `.dwg` 到底是不是 DWG —— **读魔数**取证（一个**正面**结论）

**Status**: Implemented（轮 156）· ✅ **实现了既有能力的取证**（无新代码）

## 一、动机（回到「真缺」的正路）
前几轮（`070`~`074`）全在 `composite_curve` 上打转，最后**按事实 53 强停止**。
⇒ 本轮**换一个不依赖 `mark` 的**、**可读魔数取证**的题目。

`scripts/sw_export.py` 的 `export_to_dxf` 文档串写着「导出为 **DXF/DWG** 格式」，
而 `_export_for_format` 把 **`.dwg` 与 `.dxf` 路由到同一个函数**。
⇒ ★ 那 `.dwg` 真出 DWG 吗？**可验**：
```
DXF 魔数：以 `0` + 换行 + `SECTION` 开头 —— **纯文本**
DWG 魔数：以 **`AC10xx`** 开头 —— **二进制**
```

## 二、★★ 结果：**名实相符**（正面）
```
`.dxf` ⇒ 20208 字节 · 头部 `  0\r\nSECTI` ⇒ **DXF** ✓
`.dwg` ⇒ 272032 字节 · 头部 **`AC1015`**    ⇒ **真 DWG** ✓
```

## 三、★ 一个可复用的观察
```
**`AC1015` = AutoCAD 2000 / R2000** —— **不是最新版**
⚠ 若下游要求更新的 DWG 版本：**本轮没查到通过 API 指定版本的入口**
  （`SaveAs3` 无此参数，疑为用户首选项级别 ⇒ **未验证**）
```
