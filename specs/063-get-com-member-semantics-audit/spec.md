# 063 · 审「取即调」的影响面 —— 结论是**改判**：那不是缺陷

**Status**: Implemented（轮 144）

## 一、起因
`062`（轮 143）把 `get_com_member` 的「取一个方法时会真的调一次」写成了
**「危险设计」**，并在限度里留了「⚠ 仍是『会调』的语义」。
⇒ 本轮**把影响面量清楚**，再判它到底是不是缺陷。

## 二、★ 判法（**结构**，不涉语义）
```
① 扫 scripts/ + mcp-server/ 里**无实参**的 `get_com_member(obj, "Name")` 调用点；
② 在出厂反射 iface_*.txt 里查 `Name`：**是方法？有几个参数？**
③ ★ 若它有**零参重载** ⇒ 探测调用**会成功执行**（危险面）
   若它**都要实参** ⇒ 探测调用失败 ⇒ 返回成员本身（轮 143 的修复覆盖这里）
```

## 三、★★ 影响面
```
无实参调用点: **471**
  ├─ 成员有**零参重载** ⇒ 探测调用**会执行**: **193** 处
  │    ├─ 绝大多数是**只读 getter**（GetTitle / GetPoints / IsCylinder…）⇒ **无害** ✓
  │    └─ 名字像「改东西」的: **24** 处
  │        （Insert* / Run* / Mesh* / Scale / Update* / Activate / Redraw…）
  └─ 其余 ⇒ 返回成员本身（轮 143 修复覆盖）
```

## 四、★★★ 逐条读过 **8** 处之后 —— **改判**
```
sw_simulation:  int(get_com_member(study,"RunAnalysis") or 0)        ⇒ 要的就是"调"的返回码 ✓
sw_topology:    code = get_com_member(study,"MeshAndRun")            ⇒ 同上 ✓
sw_view:        get_com_member(view,"Activate")                      ⇒ 探测即执行，正是意图 ✓
sw_gtol:        gtol = get_com_member(model,"InsertGtol")            ⇒ 执行 + 查返回 ✓
sw_mold:        feat = get_com_member(fm,"InsertMoldShutOffSurface")  ⇒ 同上 ✓
sw_drawing_view/sw_view: float(get_com_member(view,"Scale") or 0.0)  ⇒ 要的是 Scale 的**值** ✓
```
⇒ ★★ **`get_com_member` 的探测调用不是缺陷，是**被依赖的特性** ——
作者就是把它当「**取或调**」用的。**

## 五、处置（**不打断 193 处依赖**）
```
① 把正式语义写进 docstring：★「**取或调**」+ 审计量出的影响面 + 危险面；
② ★ 新增 `get_com_member_raw(obj, name)` —— **只取不调**（要方法对象时用）；
③ **没有**改成「永不调用」—— 那会打断 193 处依赖；
④ ★ **就地更正事实 84 的定性**（轮 143 写的「危险设计」）；
⑤ 审计脚本入库（可重跑）+ 6 条语义判据。
```
