# 工具栏攻关 · 规格（spec）

**编号**：201-toolbar-gaps
**日期**：2026-10-03
**来源**：用户在 2026-10-03 会话里贴的 **5 组 SolidWorks 工具栏截图**（特征 / 特征下拉 / 草图绘制 / 草图尺寸与关系 / 曲面），逐条问「能/不能」。**那 119 条就是本规格的需求原文**，落在 `docs/toolbar-ledger.json`（★ 人工读图得来）。

## 一、要解决的问题

我逐条答了「能/不能」，结果 **119 条里 87 条是「不能」或「没验过」**。用户随后要求：**「把这些不能实现的都攻关好」**。⇒ 本规格要回答的是：**那 87 条里，哪些是真能做到的、怎么做、怎么证明。**

## 三、用户故事

1. **作为设计者**，我要能画**草图的所有基本图元**（3 点矩形 / 平行四边形 / 切线弧 / 部分椭圆 / 抛物线 / 圆锥 / 周边圆 / 各槽口），这样不必因为我不会就改设计。
2. **作为设计者**，我要能用**草图的编辑工具**（剪裁 / 延伸 / 等距 / 圆角 / 草图阵列 / 移动复制旋转缩放伸展），因为改图比画图更常用。
3. **作为设计者**，我要能给草图**各类尺寸与关系**（水平/竖直/基准/链/尺寸链/路径长度 / 完全定义 / 删除关系），因为工程图要求那个口径。
4. **作为设计者**，我要能用**曲面特征**（旋转/扫描/放样/边界/平面区域/等距/展平/直纹/删除面/替换面/剪裁/加厚/使用曲面切除），因为曲面是建模的一半。
5. **作为设计者**，我要能用**特征的下拉族**（高级孔 / 螺纹线 / 各阵列变体 / 参考几何体 / 曲线各型），因为工具栏有就说明这是日常操作。

## 四、验收判据（每条都可执行）

| # | 判据 | 怎么验 |
|---|---|---|
| W1 | 台账**机器可重建**，且每条带「档」与「官方成员核实结果」 | `python tools/build_toolbar_ledger.py` 退出 0，`docs/toolbar-ledger.md` 随之更新 |
| W2 | **凡标「能」的，必须有我们自己的真机证据** | `capabilities.yaml` 的 `level: verified` + `evidence` 指向的产物文件存在且 `verdict: pass` |
| W3 | **凡新建的能力，调用形态必须与官方签名一致** | `docs/signature-audit.md` 覆盖到新模块；三源互证（CHM + swapi + 出厂类型库） |
| W4 | **凡真机建成的，判据不是返回值而是特征树/几何** | 每个新能力的 evidence 里含 `tree_before/tree_after` 或几何增量 |
| W5 | **查不到的，写明「查不到」**，不拿相似名蒙混 | 台账里 `tier=待查` 的条目带「官方源查不到」的原因 |
| W6 | **后端结构性到不了的，单列并给依据**（不假装做到） | `docs/toolbar-gaps-backend-limits.md`：线性阵列族 / `IAccessSelections` 指针族 / 结构系统 |
| W7 | 每批攻完，`release_check.py` 退出 0 且新门禁接进接线元门禁 | `python scripts/release_check.py` |

## 五、非目标（明确不做）

- **不改上游与四家的任何文件**（只读对照）。
- **不为了让台账好看而把 `stitched` 写成 `verified`**（铁律 6 + A7）。
- **不重走已走死的路**：动手前先读 `docs/dead-ends.md` 与该能力的 `limitations`。

## 六、风险与已知阻碍

| 风险 | 处置 |
|---|---|
| **pywin32 后端到不了**（`IAccessSelections` 指针族 / `FeatureLinearPattern4` 静默回 None） | 单列 W6，写明依据；**不重复试**（事实 47/369） |
| **`IModeler.Create*Surface` 返回值跨次会变**（事实 40） | 曲面**特征**与曲面**体**分开记；体那族不算「能」 |
| 官方源里**查不到入口**（如螺柱向导） | 按铁律 5 记「查不到」，不猜 |
| 每加一个能力都可能有**选择/单位/规则 3** 的坑 | 一律走本仓既有的 `sw_selection_spec` + `_mm/_deg` 边界 |

见 `tasks.md`。批次按**可核到的官方成员数**与**域价值**排序，不按截图顺序。
