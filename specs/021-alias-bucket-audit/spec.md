# 021 · 两档「别名」也全核了 —— 连自称"最强"的那档也只有 27%

**Status**: Implemented（轮 102）

## 背景
轮 101 核出「后缀候选 144」档的真实命中率只有约 25%。当时留了一句：
「另两档『别名（强）26 / 别名（弱）37』**同样是字符串匹配**，可能同样虚高」。
⇒ 本轮**全核那 63 条**。

## 结果
```
别名（强） 26 条 ⇒ ✅ 真 **7**（≈ **27%**）
别名（弱） 37 条 ⇒ ✅ 真 **6** · ⚠ 部分 14 · ❌ 假 17（≈ **16%**）
```

★ **最离谱的一处**：强档里 **8 个互不相同的曲面操作**
（`extend_surface` / `extruded_surface` / `filled_surface` / `offset_surface` /
`planar_surface` / `revolved_surface` / `thicken_surface` / `trim_surface`）
**全被配到同样两个函数** `mold_shut_off_surface, ocp_surface`。
⇒ 匹配器只认到共同后缀 **`surface`**。

## ★★ 结论：四档全都要打折
```
              条数   真    命中率
别名（强）      26     7     27%
别名（弱）      37     6     16%
后缀候选       144    36*    25%   (* 抽样外推)
真缺           132   132     —     (定义上就是缺)
------------------------------------------------
真匹配 ≈ 49  ⇒  真实缺口 ≈ 338 − 49 ≈ **289**
```
`010` 当时说 **132**。**⇒ 真实缺口是它说的两倍多。**

## ⚠ 这个数字的限度（必须一起读）
* **别名两档是全核**（63/63）；**后缀候选是抽样**（24/144）⇒ 后者有外推误差；
* 「部分」共 **16** 条口径未定，本表**不计入"真"** ⇒ 真匹配可能落在 **49~65**；
* ⇒ 结论应表述为「**真实缺口约 270~290**」，**不是**「就是 289」。

## ★ 可复用的认识
**同一个匹配器，越"强"的档也可能越不准。**
「强别名」自称「极可能同一操作」，实测 **27%** —— 与最弱的档**差不多**。
⇒ **分档的"强/弱"是给匹配规则起的名，不是给结论背的书。**
