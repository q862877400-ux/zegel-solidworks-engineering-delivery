## 三、★★★ 本批的核心：**一个官方没写的未知，用对照实验答**

```
★ 官方 Remarks 只说 "Both swChamferAngleDistance and swChamferDistanceDistance are
  **edge chamfers**" —— ★ 说明**倒的是边**，但**哪些边**、**是否取自当前选择**，**官方没写**。
⇒ ★★ 所以本批**不假设**，而是设计**对照实验**去问真机：
```
| 情形 | 结果 |
|---|---|
| 选中 `index:0` → `chamfer(2mm)` | 建出特征「**倒角1**」· 特征树 **19 → 20** |
| 选中 `index:1` → `fillet(3mm)` | 建出特征「**圆角1**」· 特征树 **→ 21** |
| ★ **清空选区**后调用 | ★ **特征树 21 → 21（没有新增）**，且返回对象**名字为空** |

```
⇒ ★★★ **证实"它作用在当前选择上"** ⇒ **本批设计成立**。
⇒ ★ 若两者相同，本批的 `selection` 就是**假设计**、必须改设计 ——
  ★ **这个对照实验的价值就在于：它能在"设计错了"的时候说话。**
⚠ ★ 但"清空选区"时它**不抛错**（静默返回无名对象）⇒
  ★ 这是本族的**静默失败点**，与 `specs/135` 的「不 start 就画线」**同型**
  ⇒ ★ 如实记进 capability 的 `limitations`，**不假称有守卫**。
```

## 四、★ 我自己在证据脚本里发现的一处**不可靠读数**

```
证据里有个 `new_names` 字段（"特征树列表**差集**"），它一度显示 `["凸台-拉伸1"]` ——
★ 而那是**基体**的名字，不是新特征！
★ 根因：**特征树的顺序会变** ⇒ 差集法会把"旧特征"看成"新的"。
⇒ ★ 处置：**断言改用「计数」与「返回对象的名字」**（两者都可靠），
  差集字段**保留但标注不可靠**。
★ 定则：**判据要选"顺序无关"的读数** —— 列表差集、集合比较这类都受顺序影响。
```

## 七、给下一批的可复用套路（增至 12 条）

```
① 先写真机探针答"对象怎么取" —— 但**先判断要不要探针**（已有证据就别重跑）
② **先核缺口本身**（缺口名是名字级匹配）③ 能力落 scripts/，不改生成物
④ 证据走工具真实路径 ⑤ 证据必带负例 ⑥ 期望值本身也要被怀疑
⑦ 长文本进源码立刻 ast.parse（含中文时**内层引号一律用「」**）
⑧ 判据用"行为"不用"类型" ⑨ 可用性看"封送形状"，不看"代数新旧"
⑩ 对外名与对内名不同时用 `param_alias`，别改能力层形参名
⑪ "不确定就不敢断言"是对的，但"不确定"先去核一分钟，别直接降级为记录
⑫ ★ **读一个"官方没写"的语义时，设计一个对照实验去问真机** ——
   而且**要事先规定"若两种情况相同就说明设计错了"**，否则实验等于没做
```
