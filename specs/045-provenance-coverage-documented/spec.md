## 二、★★ 量到的**真实**语义（四形态）
| 形态 | 结果 |
|---|---|
| 不写标记 + 2 个 def | 第一个**覆盖**、第二个**未覆盖** |
| `后续同级` + 2 个 def（同一块下）| **都覆盖** |
| `后续同级` + 另起一块 + def c | **都覆盖**（**两块接得上**）|
| ★ **def 插在来源块「上方」** | **未覆盖** ← **这才是真因** |
| `全文件` + 2 个 def | 都覆盖 |

⇒ **`后续同级定义` 不会被「截断」** —— 它覆盖到下一个块之前，而下一个块**接着往下覆盖**。
⇒ 轮 125 的真因是 `t.index("\n\n# ── 来源")` 命中了**更靠前**的那个块 ⇒
新代码被插到了它的**上方**，而块覆盖的是**下方**。
