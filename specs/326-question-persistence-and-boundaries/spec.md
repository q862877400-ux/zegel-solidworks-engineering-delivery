## §0 这一份规格要解决什么

四问的共同点：**它们都划「什么不做 / 什么不算」的界**。

| Q | 核心（逐字） |
|---|---|
| **Q8** | 「返回**持久化的** `WAITING_INPUT`、**问题对象**和回答入口，而不只是自然语言提示」；「**LLM 自己提交 `source=human` 不算人工确认**」 |
| **Q9** | 「最多 10 种自制零件、30 个装配实例、2 级装配层次」；「`READY_FOR_REVIEW` 表示自动流程完成待审核；**`DELIVERED` 还需可信人工批准**」；「**人工接管的任务要单独计数，不能计作自主完成**」 |
| **Q11** | 「**两个投入止损关口**」；「同一假设**连续三次修复失败**停止补丁式尝试」；「**Plan B：人工确认 DesignIR／选择方法**」 |
| **Q15** | 「事务边界是「**自有副本＋已验证检查点＋提交清单**」，**不是 COM 撤销栈**」；「**磁盘不足**就拒绝开始」；「执行进程**不访问公网**」 |

**★★ 这四问最容易被做假**：★ 它们都是「**声明**」——
★ 写一段文字说"我们不承诺 X"很容易，★ **难的是让那个边界真的在代码里生效**。

## §2 交付物

### Q8 —— 问题持久化

| # | 契约 | 判据 |
|---|---|---|
| **S1** | **问题对象 11 字段** | `question_id` / `run_id` / `requirement_revision` / `field` / `value_schema` / `unit` / `reason` / `blocking` / `allowed_default_ref` / `answer_source` / `status` |
| **S2** | **落盘 + 读回** | ★ 写 `output/runs/<run_id>/questions/<rev>.json` 并**读回一致** |
| **S3** | ★★ **`source=human` 必须可核** | ★ **LLM 自报 `human` 不算** —— 需**可信通道**标记 |
| **S4** | **补答拒绝旧版本** | ★ 携带**旧 `requirement_revision`** ⇒ **拒** |
| **S5** | **等待时释放执行锁** | ★ 等待用户时**不持有 COM/选区** |

### Q9 —— DoD 边界

| # | 契约 | 判据 |
|---|---|---|
| **S6** | **v1 上界四条** | 零件 ≤10 · 实例 ≤30 · 层级 ≤2 · **驱动自由度 ≤1** · **方法级节点 ≤100** |
| **S7** | **不进入自主承诺的清单** | 自由曲面 / 柔顺机构 / 任意空间机构 / 多物理场 / 未验证接触摩擦 |
| **S8** | ★★ **`DELIVERED` 需人工批准** | ★ `READY_FOR_REVIEW` ≠ `DELIVERED` |
| **S9** | ★★ **人工接管单独计数** | ★ **不得计作自主完成** |

### Q11 —— 止损关口与 Plan B

| # | 契约 | 判据 |
|---|---|---|
| **S10** | **两个止损关口** | 阶段 2 执行关口 · 阶段 4 规划关口（★ 各有**触发条件**） |
| **S11** | **三次失败停止补丁** | ★ 同一假设**连续 3 次**失败 ⇒ **停止补丁式尝试** |
| **S12** | **Plan B** | ★ 人工确认 `DesignIR`／选方法 ⇒ 系统做**确定性**部分 |
| **S13** | **失败盲题转回开发集** | ★ 看过的盲题**不再叫盲测** |
| **S14** | **允许叶子方法持续增长** | ★ **不排除一切方法增长** |

### Q15 —— 运行边界

| # | 契约 | 判据 |
|---|---|---|
| **S15** | **事务边界声明** | ★ 自有副本 + 已验证检查点 + 提交清单，★ **不是 COM 撤销栈** |
| **S16** | ★★ **无人值守需独立执行身份** | ★ **达不到 ⇒ 只提供有人值守模式**（★ 不宣称无人值守安全） |
| **S17** | **自动回收只针对自有实例** | ★ 否则**停住**（★ 不杀进程、不点保存提示） |
| **S18** | **磁盘不足就拒绝开始** | ★ **不自动清删**证据或旧 CAD |
| **S19** | **执行进程不访问公网** | ★ 网络/密级/预算**在进入云端客户端之前**控制 |

## §3 Requirements

- **FR-001**: 问题对象 MUST 有 **11 个字段**
- **FR-002**: 问题 MUST **落盘且读回一致**
- **FR-003**: ★★ **`source=human` MUST 可核** —— LLM 自报不算
- **FR-004**: 补答携带**旧 revision** MUST 被拒
- **FR-005**: 等待用户时 MUST **释放执行锁**
- **FR-006**: 系统 MUST 声明 **v1 上界**并在**超界时拒**
- **FR-007**: 系统 MUST 有**不进入自主承诺的清单**
- **FR-008**: ★★ `DELIVERED` MUST **需人工批准**
- **FR-009**: ★★ **人工接管 MUST 单独计数**
- **FR-010**: 系统 MUST 有**两个止损关口**且**可判**
- **FR-011**: 同一假设**连续 3 次**失败 MUST **停止补丁**
- **FR-012**: 系统 MUST 有 **Plan B** 路径
- **FR-013**: 看过的盲题 MUST **转回开发集**
- **FR-014**: 系统 MUST **允许叶子方法增长**
- **FR-015**: 事务边界 MUST 是**自有副本+检查点+清单**
- **FR-016**: ★★ 无人值守 MUST 有**独立执行身份**；★ 达不到 ⇒ **只提供有人值守**
- **FR-017**: 自动回收 MUST **只针对可证明自有的实例**
- **FR-018**: 磁盘不足 MUST **拒绝开始**
- **FR-019**: 执行进程 MUST **不访问公网**

---

## §4 Success Criteria

- **SC-001**: 问题对象 **11 字段齐**
- **SC-002**: 落盘**读回一致**
- **SC-003**: ★★ **LLM 自报 `human` 被拒**
- **SC-004**: **旧 revision 补答被拒**
- **SC-005**: 等待时**锁已释放**
- **SC-006**: **超 v1 上界 ⇒ 拒**（★ 四条上界都验）
- **SC-007**: 不承诺清单**可查**
- **SC-008**: ★★ **`READY_FOR_REVIEW` 不得升成 `DELIVERED`**（无人批准时）
- **SC-009**: ★★ **人工接管进单独计数**
- **SC-010**: **两个关口都可判**（★ 各有触发）
- **SC-011**: **3 次失败 ⇒ 停**
- **SC-012**: Plan B **可用**
- **SC-013**: 盲题转回**有记录**
- **SC-014**: 叶子方法增长**不被排除**
- **SC-015**: 事务边界**如实声明**
- **SC-016**: ★★ **无人值守门槛不达标 ⇒ 明说"只提供有人值守"**
- **SC-017**: 非自有实例 ⇒ **停住**
- **SC-018**: 磁盘不足 ⇒ **拒**
- **SC-019**: 公网访问 **= 0**

## §6 明确不做

- **不创建账户 / 不改注册表 / 不改系统策略**（★ Q15 L319 逐字）
- **不宣称无人值守安全**（★ Q15 L317 逐字）
- **不自动清删证据或旧 CAD**（★ Q15 L324 逐字）
- **不重写** `jobs.py` / `authorization.py` / `design_ir.py`（★ 扩展，不推倒）
