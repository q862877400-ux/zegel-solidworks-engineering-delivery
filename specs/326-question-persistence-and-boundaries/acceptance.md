## §3 ★★ 本机运行模式（★ 如实报 —— 本规格最重要的一条）

```
mode = attended              ★ 只提供有人值守
unattended_claim = False     ★★ 不宣称无人值守安全

★ 缺四项：
  separate_execution_identity     独立执行身份
  business_files_readonly         业务文件对执行进程不可写
  os_level_isolation              OS 级隔离（或等效沙箱）
  no_prompt_based_isolation       ★ 不能只靠提示词
```

**★ 依据**（★ Q15 L317 + L319 逐字）：

> 「对无人值守安全承诺，必须有**独立执行身份或等效沙箱**……
> **当前环境若达不到此门槛，就只提供有人值守模式，不宣称无人值守安全**」
> 「本轮**不创建账户、不更改注册表或系统策略**」

**★★ 这一条是本规格**最容易被做假的地方** ——
★ 写一段文字说"我们很安全"很容易，★ **难的是如实说"我们做不到"**。

## §5 ★★ 本规格的设计要点：**判据要落在"能不能假装"上**

★ 这四问都是「**声明**」⇒ ★ 最容易变成**只写一段文字**。★ 我的处置：

| 声明 | 判据落在哪 |
|---|---|
| 「LLM 自报 `human` 不算」 | ★ **要"通道证明"** —— `channel_proof ∈ TRUSTED_CHANNELS`，★ **LLM 拿不到** |
| 「`DELIVERED` 需人工批准」 | ★ **同口径** —— `approved_by ∈ TRUSTED_APPROVERS` |
| 「人工接管不能计作自主完成」 | ★ **两个计数器分开**（`autonomous_only` vs `total`） |
| 「不冒称原地回滚成功」 | ★ `rollback_claim=False` **写死在返回值里** |
| 「不宣称无人值守安全」 | ★ `unattended_claim` **由四个门槛算**，★ 不满足 ⇒ **False** |
| 「不自动清删证据」 | ★ `auto_delete_evidence=False` **写死在返回值里** |
| 「不杀进程、不点保存提示」 | ★ `kill_process=False` · `click_save=False` **写死** |
| 「看过的题不再叫盲测」 | ★ **从 `blind` 里移走**（★ 不是"标记一下"） |

**★★ 共同点**：★ 每一条**都有一个字段**承载它，★ 而那个字段**由代码算**，
★ **不是**由调用方传进来。
