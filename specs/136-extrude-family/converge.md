```

⇒ ★ 三种验证形态**都落成数字**，可复跑、可进 CI。
```

## 四、★ 一个"没做"的核对，也是产物

```
为判断 `chamfer` 能不能进本批，按铁律 4 核了 `InsertFeatureChamfer`：
   · 枚举 `swChamferType_e.swChamferAngleDistance = 1`（swapi 与反射**两源一致**）
   · 实现传 `(Options=4, ChamferType=1, Width=distance, Angle=angle_rad, …)`
     ⇒ 与官方「Width/Angle 只在 AngleDistance 下有意义」**一致** ✓
⇒ ★★ 结论：**它的调用形态是对的**；但它**没有 `edges` 参数** ⇒ 需要 `selection` 包装层
⇒ ★ **核对没有白做** —— 它产出了"**下一批可以直接用**"的结论，而不是"没做"。
★ 顺带说明本批**只做 3 个**的理由：**一个批次混两种包装形状会让证据与说明都变复杂**。
```
