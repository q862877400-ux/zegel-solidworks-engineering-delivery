### 5. `solidworks_sketch_add_polygon` —— `radius_mm` 的描述是「内切圆半径」，官方口径里它是**顶点距离** —— **存疑**

**一句话依据**：官方第 4/5 个形参是「a vertex」，第 8 个 `Inscribed` 只管**构造圆画内还是画外**、不管尺寸；所以 `radius` 定的是外接（顶点）半径，不是内切圆半径 —— 但 `Inscribed=True` 也确实传了，所以「内切圆方式」这半句站得住，故只判**存疑**。

**仓内那一段**（`mcp-server/tool_specs_batch54.py`）：
```
            Param("radius_mm", float, description="内切圆半径，毫米"),
```
```
        doc="★ **在当前草图里画正多边形**（**内切圆**方式 —— 官方 `CreatePolygon` 的口径）。" + _GEOM_NOTE,
```

**目标那一段**（`scripts/sw_part.py`）：
```
    return model.SketchManager.CreatePolygon(cx, cy, 0, cx + radius, cy, 0, sides, True)
```

**官方那一段**（`C:\swapi\types\ISketchManager\CreatePolygon.md`）：
```
- **Xp**: X coordinate for a vertex
- **Inscribed**: True to show an inscribed construction circle, false to show a circumscribed construction circle
```
⚠ 若真是内切圆半径，正 n 边形的顶点应落在 `cx + r / cos(π/n)`，而代码落在 `cx + r` ⇒ 差一个 `cos(π/n)`（`sides=6` 时约 0.866）。**因代码传了 `Inscribed=True`，也可能作者本就指「构造圆内接」这一层，故不判成立。**
