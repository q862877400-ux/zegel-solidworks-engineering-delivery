## 一 · 钣金 gusset：官方要**两条腿（两个面）**，`pre_call` 只选 **1 个面** —— **判定：成立**

**一句话依据**：官方 `ISMGussetFeatureData` 的 Remarks 明写加强筋的两条腿要「**Two** flat faces of a bend」，而 `_pre_gusset` 走 `resolve_selection`，**结构上只会选出一个实体**。

**① 仓内那一段**（`mcp-server/tool_specs_batch4.py`）：

```python
def _pre_gusset(params):
    _select(params, "FACE")
```

配合 `scripts/sw_selection_spec.py`：

```python
def resolve_selection(model, selector, kind: str, *, body_index: int = 0) -> int:
    """同 :func:`resolve_entity`，但**只返回回读到的选区计数**。"""
    resolve_entity(model, selector, kind, body_index=body_index)
```

⇒ `resolve_selection` 走的是 `resolve_entity` → **单个对象** → `select_object` → `Select4` 一次 ⇒ **恒为 1 个面**（`_select(params, "FACE")` 的返回值只是**计数**，不改变数量）。

**② 官方/目标那一段**（`C:\swapi\types\ISMGussetFeatureData`_overview.md`` 的 `## Remarks` 第 2 步）：

```
2. Pre-select faces, lines, edges, vertices, or points as follows:

To...
Call [[IModelDocExtension::SelectByID2]] to select...

Specify the legs of the gusset feature

   - Two flat faces of a bend.

   - or -

   - Two flat faces adjacent to a cylindrical bend face.
```

**③ 官方例子佐证**（`C:\swapi\examples\Create_Sheet_Metal_Gusset_Example_CSharp.md`）—— 官方确实连选**两个**面，第二次 `Append=True`：

```csharp
boolstatus = Part.Extension.SelectByID2("", "FACE", -0.0538403893476698, 0.0036701308754914, 0.05530817474488, false, 0, null, 0);
boolstatus = Part.Extension.SelectByID2("", "FACE", -0.0177780871801474, -0.0307393226379986, 0.0341128529187245, true, 0, null, 0);
swFeatData = (SMGussetFeatureData)Part.FeatureManager.CreateDefinition((int)swFeatureNameID_e.swFmSMGusset);
```

**④ 佐证我们自己也承认了这一点**（`scripts/sw_sheet_metal.py` 的 `create_gusset` 来源块）：

```
# ⚠ 支撑面须由调用方先用 SelectByID2 选好；本函数不代为选面。
```

⇒ ★ 工具层只交给调用方**一个** `selection` 参数、只选**一个**面 ⇒ 按官方流程无法提供加强筋的**两条腿**。

## 二 · 边法兰：官方要求「先 `InsertSketchForEdgeFlange`，再 `AddEdges(边数组, 草图数组)」，我们**两步都没做** —— **判定：成立**

**一句话依据**：官方 `AddEdges` 的 `## Remarks` 把「先建轮廓草图」列为**调用前必须**，官方例子在 `CreateFeature` 前必调 `AddEdges`，而 `create_edge_flange` 的 `_apply` **从头到尾没有 `AddEdges`** ⇒ 选中的边进不了法兰。

**① 仓内那一段**（`scripts/sw_sheet_metal.py` 的 `create_edge_flange`）：

```python
def create_edge_flange(model, spec: EdgeFlangeSpec):
    """@brief 在已选中的边上创建原生边法兰。

    调用前必须先用 ``sw_part._select_by_id`` 把目标边选入选区。
    """
    spec.validate()

    def _apply(data):
        data.UseDefaultBendRadius = bool(spec.use_default_radius)
        data.BendRadius = float(spec.bend_radius)
        data.BendAngle = float(spec.angle)
        ...
        data.UseDefaultBendAllowance = True

    return _create_from_definition(model, SW_FM_EDGE_FLANGE, _apply)
```

⇒ `_apply` 里 **没有 `data.AddEdges(...)`**，全函数 **没有 `InsertSketchForEdgeFlange`**（`mcp-server/tool_specs_batch4.py` 的 `pre_call=_pre_edge_flange` 也只做 `_select(params, "EDGE")`）。

**② 官方/目标那一段**（`C:\swapi\types\IEdgeFlangeFeatureData\AddEdges.md` 的 `## Remarks`）：

## 三 · 焊件 end cap / weldment gusset：官方要的是「**端面**」/「**支撑腿**」，`pre_call` 按遍历顺序取前 N 个面、**零语义筛选** —— **判定：成立**

**一句话依据**：官方前置对面有**语义限定**（end face / supporting leg），而 `_select_faces_for` 是「第一个体的 `GetFaces()` 前 `count` 个」，**不看面是什么** ⇒ 前置在「数量」上成立、在**语义**上不成立。

**① 仓内那一段**（`mcp-server/tool_specs_batch74.py` 的 `_select_faces_for`）：

        sm = get_com_member(model, "SelectionManager")
        picked = 0
        for body in list(get_com_member(model, "GetBodies2", 0, True) or []):
            for face in list(get_com_member(body, "GetFaces") or []):
                if picked >= count:

                try:
                    _select_com_object(face, append=(picked > 0), mark=mark)

⇒ 判定条件只有 `picked >= count`，**没有任何「这是不是端面 / 是不是支撑腿」的检查**。

**② 官方/目标那一段 · 顶端盖**（`C:\swapi\types\IFeatureManager\InsertEndCapFeature3.md` 的 `## Remarks`）：

## 四 · `_select_faces_for` 调 `_select_com_object` **没传 `model=`** ⇒ mark 保真分支走不到 —— **判定：存疑**

**一句话依据**：`sw_part._select_com_object` 里**只有传了 `model` 才会走 `Select4` + `ISelectData(Mark=mark)`**；本调用点没传 ⇒ mark=1 只靠**已废弃**的 `Select2` 兜底，而 `Select4` 兜底分支**会丢 mark**。

**① 仓内那一段 · 调用点**（`mcp-server/tool_specs_batch74.py`）：

```python
                    _select_com_object(face, append=(picked > 0), mark=mark)
```

⇒ ★ **没有 `model=` 形参**。

**② 仓内那一段 · 被调方自己写明的后果**（`scripts/sw_part.py`）：

```python
def _select_com_object(obj, append=False, mark=0, model=None):
    ...
    #:   ★ 而本函数**原先**给 `Select4` 传 `_empty_callout()`（**空 VARIANT**）
    #:     ⇒ ★★ **`Select4` 分支的 `Mark` 永远是 0**。
    ...
    #:   ★ 修法（★ 铁律 4「**取后继，不取废弃成员**」）：★ 传了 `model` ⇒ **先走 `Select4` + `SelectData`**
    #:     （`ISelectionMgr.CreateSelectData()` 建对象、设 **`Mark = mark`**）
```

```python
    if model is not None:
        #: ① ★ 首选**后继成员** `Select4` + 真 `ISelectData`（★ 这样 `mark` 才真的写得进去）
        try:
            from sw_connect import get_com_member as _gcm
            ...
            _data = _gcm(_sm, "CreateSelectData") if _sm is not None else None
            if _data is not None:
                _scm(_data, "Mark", int(mark))
```

```python
    #: ③ ★ 最后退回 `Select4` + 空 VARIANT（★ 保原行为；⚠ **它丢 mark**，已知）
    _m4 = getattr(obj, "Select4", None)
```

**为什么判「存疑」而不是「成立」**：★ 请求的 mark 数值（1 / 0）本身与官方**一致**；★ mark 是否**真丢**，取决于运行时第②分支（`Select2`，官方已标 `Obsolete`）是否成功 —— ★ **本片不跑真机，不下断言**。
★ 只登记**一处可直接核实的事实**：`_select_faces_for` 走的这条路径，`sw_part.py` 自己文档里那套「传 `model` 才能保住 mark」的修法**没有生效**。
