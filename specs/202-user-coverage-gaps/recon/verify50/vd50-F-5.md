## 1 · knit：`InsertSewRefSurface` 的 mark=1 请求能不能真的落到选区上 —— **存疑**

**判定：存疑** —— ★ 请求值 `1` 与官方一致，★ 但**投递这个值的函数没有 `model`**，
于是**唯一保 mark 的分支不可达**，一旦走到兜底分支 mark 会被**丢成默认**（官方要求的是 1）。

**官方那一段** —— `C:\swapi\types\IFeatureManager\InsertSewRefSurface.md` 的 `## Remarks` 首句：
```
Make selections using [[IModelDocExtension::SelectByID2]] with a mark number of 1. See the SOLIDWORKS Help for information about what entities are valid for selection.
```

**仓内那一段（三片，串成一条链）** —— `scripts/sw_surface_features.py`，缝合包装先请求 mark=1：
```python
    selected = _select_all_surface_faces(model, mark=1)
```
同一文件的选择助手，★ 它**怎么把 mark 交出去**：
```python
def _select_all_surface_faces(model, mark: int = 1) -> int:
    """★ **把所有曲面体的面按对象选中**（★ 回**选中数** —— ★ 事实 8：不信返回值，只信回读计数）。"""
    from sw_connect import get_com_member as _get
    from sw_part import _select_com_object as _sel
    ...
                if _sel(f, append=True, mark=mark):
```
★ 注意**没有 `model=`**；于是 `scripts/sw_part.py` 的 `_select_com_object` 里那条**唯一保 mark** 的分支
（`ISelectData.Mark` → `Select4`）**进不去**：
```python

    ...
    if model is not None:
        #: ① ★ 首选**后继成员** `Select4` + 真 `ISelectData`（★ 这样 `mark` 才真的写得进去）
```
落到的兜底分支，★ **仓内自己注明它丢 mark**：
```python
    #: ③ ★ 最后退回 `Select4` + 空 VARIANT（★ 保原行为；⚠ **它丢 mark**，已知）
```
（★ 中间那条能收 mark 的是**已废弃**的成员 —— `C:\swapi\types\IEntity\Select2.md` 逐字
`Obsolete. Superseded by [[IEntity::Select4]].`，而 `C:\swapi\types\IEntity\Select4.md` 的 `## Signature` 逐字
`**Signature**: System.bool Select4( System.bool Append, SelectData Data )` ⇒ ★ **`Select4` 这一代没有 mark 形参**。）

**一句话依据**：官方要 mark **1**、我们请求的也是 **1**，★ 但请求经 `_select_com_object(obj, append, mark)` **不带 `model`** 时
只能走已废弃的 `Select2` 或官方自承「**它丢 mark**」的兜底分支 ⇒ mark 可能变成默认 0，
**而官方 `Select4` 页通篇没写默认 mark** ⇒ **值对了不等于送到了**，判不了死、也不是水。
