## 一、对不上的 2 处（成立）

### ★ 1 · `solidworks_mold_parting_line` —— 官方要 mark 1 + mark 4，本仓一个 mark 都不传

**判定：成立。**
**一句话依据**：官方 Remarks 给了完整 mark 表（方向 = 1 / 分型线边 = 4），而仓内 spec 没有 `pre_call`、目标函数体一个实体都不选 ⇒ 经 MCP 工具层这两个 mark 永远不会被设上。

**① 仓内那一段（spec 侧 · 证明没有 `pre_call`）** —— `mcp-server/tool_specs_batch1.py`

```python
    ToolSpec(
        name="solidworks_mold_parting_line",
        title="Insert Mold Parting Line",
        module="sw_mold", function="insert_parting_line",
        inject="model",
        params=[
            Param("draft_analysis", bool, default=True,
                  description="The official single parameter. Its exact meaning is UNVERIFIED; "
                              "kept True to match the reference usage."),
        ],
        doc=("Insert a mold parting line. Select the draft-direction reference first "
             "(edge/plane/axis); without it the call inserts nothing."),
    ),
```
（整个 `ToolSpec(...)` 里**没有** `pre_call=`、也没有 `derived_args=`。）

**② 仓内那一段（函数侧 · 证明它不建选区）** —— `scripts/sw_mold.py`

```python
    fm = get_com_member(model, "FeatureManager")
    feat = get_com_member(fm, "InsertMoldPartingLine", bool(draft_analysis))
```
（同模块的 import 行只从 `sw_connect` 取三个成员：`get_com_member, call_com_member, set_com_member` —— 全文没有 `SelectByID2` / `Select4` / `mark`。）

**③ 官方那一段** —— `C:\swapi\types\IFeatureManager\InsertMoldPartingLine.md` 的 `## Remarks`


**第二源互证**（`AI Solidworks/官方文档/SWhelp/sldworksapi/...IFeatureManager~InsertMoldPartingLine.html` 去标签后逐字）：
`Before calling this method, you must select the direction of pull and the edges for the parting line by calling IModelDocExtension::SelectByID2 with the following Marks: Selection Mark Direction of pull 1 Parting line edges 4`

**★ 不是「能力坏了」**：仓内自己已有真机证据证明**函数层在 mark 给对时是通的** —— `capabilities.yaml` 的 `mold_parting_geometry` 写着
「按官方 Remarks 的 mark 表（**direction of pull = 1** · **parting line edges = 4**）… 边按**中点**… 用 `SelectByID2` 选 ⇒ **回读 `GetSelectedObjectCount2(-1)` = 5**（1 基准面 + 4 条边）· `insert_parting_line` ⇒ **`分型线1`**」。
★ 缺口**只在工具层**：那条证据是 `tools/prove_mold_parting_line_marks.py` 这个**独立探针**在工具层之外做的。

**★ 候选实现里的 mark 是对的，别重复修**：本仓的预选候选文件已经按官方表取对了 ——
`specs/202-user-coverage-gaps/recon/precall-cand/precall-cand-A.py`：`PULL_MARK = 1     # InsertMoldPartingLine.md §Remarks 表格「Direction of pull」行` · `LINE_MARK = 4     # InsertMoldPartingLine.md §Remarks 表格「Parting line edges」行`；

★ 但 `mcp-server/` 全目录 grep `_pre_mold_parting` / `PULL_MARK` **零命中** ⇒ 它们**尚未接进任何 `ToolSpec`**。

### ★ 2 · `solidworks_mold_parting_surface` —— 官方要 mark 1 + mark 4，本仓一个 mark 都不传

**判定：成立（有条件触发）。**
**一句话依据**：官方 Remarks 说「模型里还没有分型线特征时」必须先选拔模方向 mark 1 + 分型线边 mark 4，而仓内 spec 无 `pre_call`、函数体不建选区 ⇒ 走工具层且模型尚无分型线时，这两个 mark 不会被设上。

**① 仓内那一段（spec 侧）** —— `mcp-server/tool_specs_batch9.py`

```python
    ToolSpec(
        name="solidworks_mold_parting_surface",
        title="Insert Mold Parting Surface",
        module="sw_mold", function="insert_parting_surface",
        inject="model",
        doc="Insert the mold parting surface.",
        param_alias={},
        params=[
            Param("surface_type", int, default=0, description="Official surface type enum value."),
```
（**没有** `pre_call=`、**没有** `derived_args=`。）

**② 仓内那一段（函数侧）** —— `scripts/sw_mold.py`

```python
    fm = get_com_member(model, "FeatureManager")
    # 位置严格照官方：Int32, Boolean, Boolean, Double, Double, Int32, Double, Boolean
    feat = get_com_member(
        fm, "InsertMoldPartingSurface",
```

**③ 官方那一段** —— `C:\swapi\types\IFeatureManager\InsertMoldPartingSurface.md` 的 `## Remarks`

```
f a parting line feature does not yet exist in the model, you must first select the direction of pull and the edges for the parting line using [[IModelDocExtension::SelectByID2]]. For example, a face (direction of pull) has a mark of 1 and edges (parting lines) a mark of 4.
```

**第二源互证**（`...IFeatureManager~InsertMoldPartingSurface.html` 去标签后逐字）：
`f a parting line feature does not yet exist in the model, you must first select the direction of pull and the edges for the parting line using IModelDocExtension::SelectByID2 . For example, a face (direction of pull) has a mark of 1 and edges (parting lines) a mark of 4.`
★ 注意官方那张表**以举例形式给出**（「For example」）—— 分型线与分型面两条 Remarks 的 mark 表**逐字同形**（1 / 4），故可共用一个 `pre_call`。

**★ 仓内自己标注的未验项**：`capabilities.yaml` 的 `mold_parting_geometry` 写着
「⚠ **仍未验的三个**：`insert_parting_surface` · `insert_shut_off_surface` · `insert_core_cavity_solids`（★ 硬约束③：没有 pass 不升）」。
⇒ 与第 1 条**共用同一个 `pre_call`** 即可（官方两条 mark 表同形），边际成本≈0。
