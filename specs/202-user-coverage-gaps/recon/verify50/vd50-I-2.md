## 〇 · 先把两处的**结构关系**说清楚（这一步决定了后面能报什么、不能报什么）

`docs/dead-ends.md` 不是独立写的档案，它是 `tools/gen_dead_ends.py` 从 `capabilities.yaml` **机械筛**出来的：
`capabilities[].limitations[]` → 正则 `DEAD` 命中 → 原样贴出（★ 不摘要）。

**仓内那一段**（`tools/gen_dead_ends.py`）：
```
DEAD = re.compile(
    r"(强停止|全部失败|都失败|不可调用|穷尽|已穷尽|到不了|走不通|停手|停止试|"
    r"次全部|无法|不可行|此路不通|验不过|框架性|架构性|后端限制|"
    r"降为 stitched|需要用户提供|本机没有|失败点.*漂移|未被?穷尽验证)")
```
同文件的注释把口径写死：
```
★ 只挑**表示"试完了 / 走不通 / 有硬限制"**的措辞（见 `DEAD` 正则）——
   ★ 而不是所有 limitations（★ 那有几百条，★ 读不完）。
```

**目标那一段**（`tools/gen_dead_ends.py` 的用法自述）：
```
python tools/gen_dead_ends.py            # 写 docs/dead-ends.md 并打印统计
python tools/gen_dead_ends.py --check    # 只比对（★ 供门禁用）：文件过期则 exit 1
```

⇒ **推论 A：`dead-ends.md ⊆ capabilities.yaml` 恒成立** ⇒ 「只在 `dead-ends.md` 记了、`capabilities.yaml` 没记」在结构上不可能发生。
实测 `--check`（只读）：
```
✓ `docs/dead-ends.md` 是最新的（46 条 / 29 能力）
```
⇒ 真正可报的只有两类：**① 正则漏网导致「只在 `capabilities.yaml` 一边」的真死路** · **② `dead-ends.md` 抄进来的那一条已被 `capabilities.yaml` 同条目更新的说法推翻**。

本片覆盖面：模具 3 条 + 仿真 6 条 + 拓扑 4 条 = **12 个能力 / 86 条 limitations**；`dead-ends.md` 对这 12 个能力只开了 **6 个分节、9 条**。
