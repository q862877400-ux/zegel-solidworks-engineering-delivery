## 二 · 对不上的 4 条（逐条两段原文）

### 1. `solidworks_fillet` —— 官方 Simple fillet 要 **Mark = 1**，我们一个 mark 都没给

**官方原文**（`C:\swapi\types\IFeatureManager\FeatureFillet.md` · `## Remarks`）：

> Simple fillets
>
> 1. Call [[IModelDocExtension::SelectByID2]] with Mark = 1 to select the edges to fillet.
>
> 2. Specify Ftyp with [[swFeatureFilletType_e]].swFeatureFilletType_Simple.

**仓内原文**（`scripts/sw_part.py::fillet`）：

```python
def fillet(model, radius, edges=None):
    return model.FeatureManager.FeatureFillet(
        195, radius, 0, 0, None, None, None
    )
```

第 3 个实参是 `Ftyp = 0`，而 `C:\swapi\enums\swFeatureFilletType_e.md` 逐字 `swFeatureFilletType_Simple | 0`
⇒ **走的就是官方那条 Simple 分支**，而那条明写「Mark = 1」。

选区侧的原文（`scripts/sw_selection_spec.py::select_object`）：

```python
def select_object(model, obj, *, append: bool = False) -> int:
    get_com_member(obj, "Select4", bool(append), _empty_callout())
```

`Select4` 第 2 形参是 `ISelectData`，传空 VARIANT ⇒ `Mark` 从未被写进去。
**仓内自己已经写明了这件事**（`scripts/sw_part.py::_select_com_object` 的注释）：

> ③ ★ 最后退回 `Select4` + 空 VARIANT（★ 保原行为；⚠ **它丢 mark**，已知）

而 `tool_specs_batch23.py::_select_edge` 走的正是 `resolve_selection(...)` → `resolve_entity` → `select_object`。

**判定：成立。** 官方对「Simple fillet」逐字要求 Mark = 1，本工具走的正是这条分支，而我们的选区 mark 恒为 0（未设）。
（附注，不另计一条：`FeatureFillet` 官方页首行即 `Obsolete. Superseded by [[IFeatureManager::FeatureFillet2]].`，
`FeatureFillet3` 的 Remarks 又写「As of SOLIDWORKS 2020, this method is obsolete for creating: constant radius fillets …
use [[IFeatureManager::CreateDefinition]], [[IFeatureManager::CreateFeature]], IPartialEdgeFilletData, and ISimpleFilletFeatureData2」——
即这条调用路径整体已被官方标过时；本条只判「selection 参数对不对」。）

### 2. `solidworks_sheet_metal_create_gusset` —— 官方要**两个**折弯平面当腿，我们只能给**一个**面

**官方原文**（`C:\swapi\types\ISMGussetFeatureData\_overview.md` · `## Remarks`）：

> 2. Pre-select faces, lines, edges, vertices, or points as follows:
>
>    To...
>
>    Specify the legs of the gusset feature
>
>    - **Two flat faces of a bend.**
>
>    - or -
>
>    - Two flat faces adjacent to a cylindrical bend face.
>
>    - or -
>
>    - One cylindrical bend face.

**仓内原文**（`mcp-server/tool_specs_batch4.py`）：

```python
def _pre_gusset(params):
    _select(params, "FACE")
```

```python
def _select(params, kind: str):
    from scripts.sw_selection_spec import resolve_selection
    return resolve_selection(_model(), params.selection, kind)
```

```python
Param("selection", str,
      description="Declarative FACE selection: '__current_selection__' or 'index:<n>'."),
```

`index:<n>` 这条路在 `scripts/sw_selection_spec.py::resolve_entity` 里是 `items = entities_on_body(...)` → `select_object(model, obj)`，
**恒定只选中 1 个面**；`__current_selection__` 这条路因为 `pre_call` 跑在 `inject` **之后**、而 `RESOLVERS["model"]` 会清空选区
（`tool_specs_batch74.py` 里记着这条实测：「选完 2 个面 `mark1=2`，调过 `RESOLVERS['model']` 之后变成 `mark1=0`」），
实际到 `pre_call` 时选区已空 ⇒ 直接抛错。

**判定：成立。** 官方对「腿」给的是**两个**折弯平面（只有「一个圆柱折弯面」那一条分支是单面），而本工具无论哪条路都只能交出**一个**面。

### 3. `solidworks_weldment_insert_end_cap` —— 官方要「结构构件的端面」，我们取第一个体的第一张面；且工具 doc 自称「不代选」与 `pre_call` 矛盾

**官方原文**（`C:\swapi\types\IFeatureManager\InsertEndCapFeature3.md` · `## Remarks`）：

> Before calling this method, **select one or more end [[faces]] of a structural member** in the graphics area.

官方例子（`C:\swapi\examples\Insert_Weldment_End_Cap_Example_VB.md`）也确是**按坐标选两张面**、两次都 `mark=0`：

```vbnet
boolstatus = Part.Extension.SelectByID2("", "FACE", 0.58771345904097, 0.614999999999952, -1.01293869257864, True, 0, Nothing, 0)
boolstatus = Part.Extension.SelectByID2("", "FACE", -1.24763445314215E-02, 0.614999999999839, -1.0014248149476, True, 0, Nothing, 0)
```

**仓内原文**（`mcp-server/tool_specs_batch74.py`）：

```python
pre_call=_select_faces_for(0, 1),
```

```python
for body in list(get_com_member(model, "GetBodies2", 0, True) or []):
    for face in list(get_com_member(body, "GetFaces") or []):
        if picked >= count:
            break
        _select_com_object(face, append=(picked > 0), mark=mark)
```

即：**按体号 0 的 `GetFaces()` 枚举顺序取前 1 张**，与「是不是结构构件的端面」毫无关系。
更硬的矛盾在同一个 ToolSpec 的 doc 里：

> "★★ **官方前置（Remarks 逐字）**：\"Before calling this method, **select one or more end "
> "faces** of a structural member in the graphics area.\" ⇒ ★ 调用前必须在图形区选中端面；"
> "★ 本工具**不代选**（★ 面没有可用名字 —— 已知事实 32；★ 且规则 3 禁裸坐标），"
> "★ 只**回读选区计数**写进 `preconditions_held`。"

doc 逐字说「**不代选**」，而同一 spec 上挂的 `pre_call` 恰恰**代选了**一张面；且 params 里**没有 `selection`**，
调用方根本没有途径说出「哪张才是端面」。

**判定：成立。** 官方要求的对象是「结构构件的端面」，我们给的是「第一个体的第一张面」；mark=0 与官方例子一致（这部分对），
但**实体身份**对不上，且工具自述与代码自相矛盾。

### 4. `solidworks_weldment_gusset_create` —— 官方要「这两张面必须是这个加强筋的两条支撑腿」，我们取第一个体的前两张面

**官方原文**（`C:\swapi\types\IFeatureManager\InsertGussetFeature3.md` · `## Remarks`）：

> Before calling this method, you must call [[IModelDocExtension::SelectByID2]] to select **two faces that are the supporting legs of this gusset** with a Mark of 1.

**仓内原文**（`mcp-server/tool_specs_batch74.py`）：

```python
pre_call=_select_faces_for(1, 2),
```

复用同一个 `_select_faces_for`（见上一条的逐字片段）⇒ 按体号 0 的 `GetFaces()` 顺序取**前两张**，
不判断它们是否相交、是否是两条支撑腿；params 里同样**没有 `selection`**。

**判定：成立。** mark=1、数量=2 都与官方逐字一致（这部分对），但官方附加的语义条件「**that are the supporting legs of this gusset**」
我们无法满足也无法让调用方表达 ⇒ 实体身份对不上。
