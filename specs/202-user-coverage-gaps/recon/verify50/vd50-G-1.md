```python
def _file_signature(path):
    """返回文件存在性证据，用于识别本轮真实产物。"""
    target = Path(path)
    if not target.is_file():
        return None
    stat = target.stat()
    return stat.st_size, stat.st_mtime_ns
```

★ `is_file()` 判「存在」，`st_size` 判「非空」⇒ 与判据逐字对上。
