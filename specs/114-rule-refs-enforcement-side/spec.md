# 114 · 「引用的 R 编号」覆盖面从段名扩到**执行侧** —— 新检查立刻抓到一处

**Status**: Implemented（轮 194）

## 一、起因
```
轮 193 的未查证项：「段名引用的编号」只覆盖**段名**，**函数体/错误信息里未纳入**。
```

## 二、★★★ 先测量（别假设）
```
全仓库引用 R 编号的文件共 **17 个**：
  scripts/check_*.py 3 个 · scripts/其它 *.py 4 个 · tests/*.py 5 个 · docs/*.md 5 个
⇒ ★ 段名只覆盖**极小一块**
★ 而唯一的"未登记" R99 出现在 `tests/` —— 那是轮 193 我**故意**写的**负例**
  ⇒ **没有真实缺陷**（如实说：这次测量**没有**发现违规）
```

## 三、★★★ 扩大覆盖面到「执行侧」，并**声明不守什么**
```
新增 `unregistered_refs(glob, registry, base=None)`：扫 `scripts/*.py` 里的 R 编号

守：· `scripts/*.py` 里出现的每个 R 编号都必须登记
    · 登记表**无缺号**（R1..Rmax 连续）
    · **读不出登记表 ⇒ 报**（不是静默通过）
不守（**如实声明**）：
    · `tests/` —— **负例测试必须能写出未登记编号**来证明判据有牙
      ⇒ 纳进来会**把负例判成违规**
    · `docs/`（ROADMAP / known-facts / specs）—— 那是**历史记录**，
      记的是"当时引用过什么"，**不该被后来的登记表追着改**
    · **字符串拼接出来的编号** —— 静态看不见
⇒ 实测：执行侧引用 R 编号的共 **7 个文件**，**全部已在册**（★「扩了覆盖面而结论不变」，不是"没生效"）
```

## 四、★★★ 而新检查加完**立刻抓到一处** —— 所以它不是装饰
```
[FAIL] R 编号登记表
- `scripts/check_union_conventions.py` 引用了未登记的 **R99** ⇒ 执行侧引错编号 = **执行错规则**
```
```
来源：轮 193 我在 `check_rule_registry` 的 docstring 里写了**举例**「如 `R99`」⇒ 新判据扫到了它。
⇒ ★★ **判定与修法**：那是**举例**而非**引用**；而**判据分不出这两件事**。
⇒ ★ **与其去剥注释/文档串**（脆弱，且事实 60/61 记过"剥注释"的代价），
  **不如规定「举例不写成真编号」** ⇒ 改成 `` R<n> `` 占位。
⇒ ★ 一条**可操作**的纪律：**在本文件里举例请用 `R<n>` 占位，不要写具体编号**。
  （★ 让**举例本身不构成引用**，比让判据去猜"这是不是举例"更稳。）
```
★ 这正好复刻**轮 59 的 R13 故事**：新门禁加完**立刻抓到一条真东西** ⇒ 证明它**有效，不是装饰**。
