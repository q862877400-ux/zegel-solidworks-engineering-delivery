# 068 · 把「查残留模态框」的 21 份复制全量换成共享实现

**Status**: Implemented（轮 149）

## 一、起因
`067`（轮 148）查出：`tools/` 下 **21 个文件**各抄了一份 `modal_dialogs`，
**每份都带 `IsWindowVisible` 过滤** ⇒ 实测 SolidWorks 的 **49 个顶层窗口里只有 1 个可见**
⇒ 每份都**漏检 48/49（约 98%）**。那条检查守的是**每轮收尾的安全底线**。
⇒ 本轮**全量迁移**。

## 二、★ 迁移手法（两条关键，都来自本会话的教训）
```
① **改函数体、不改调用点**
   ⇒ 21 个调用点原样不动 ⇒ 风险面小得多（轮 145 的教训：批量改会弄坏文件）
② **导引用函数内双路 try/except**
   ⇒ ⚠ 第一版直接写 `sw_connect.residual_dialogs(...)` 就 **NameError** 了 ——
     因为那些工具**并没有**把 `sw_connect` 当模块导入
   ⇒ 改成照本仓既有模式：`try: from scripts.sw_connect import … / except: from sw_connect import …`
```

## 三、结果
```
21 个文件全部迁移完成（0 跳过）
★ 端到端实测：收尾那行的输出从  「无」
                   变成  「扫了 49 个窗口 · 无模态框」
⇒ ★★ **空列表第一次有了意义**（此前无法区分「没有模态框」与「没扫到任何窗口」）
⚠ 唯一豁免：`tools/probe_window_vs_graphics.py` —— 它的 `main_windows()` **本身**
  要用可见性做对照实验，且**不在收尾路径上**。
```

## 五、⚠ 我这轮又弄坏了一次东西（如实记）
```
我用 PowerShell 取门禁给的"该改成什么"那一行时，正则**没匹配上** ⇒ `$need` 是 `$null`
⇒ 而脚本**照样**把那行**替换成了空行** ⇒ **`harvest-report.md` 被写坏**
  （门禁下一轮报「读不出『偏离上游：…』那行 ⇒ 报告已损坏」）
⇒ 修法：`git checkout -- docs/harvest-report.md` 恢复，再用**断言过匹配**的脚本改。
★ 教训：**"取一行 → 改一行"的脚本必须对"没取到"显式失败**，
  而我这一版**把 `$null` 当成"空字符串"写进去了** ——
  与事实 48 定则②（批量脚本跑完要核对落盘）同族。
```
