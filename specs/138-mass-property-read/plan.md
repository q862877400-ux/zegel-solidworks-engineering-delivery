## 二、★★★ 探针要答的三问，以及**为什么必须实测**

```
① 取法：`CreateMassProperty` 是属性还是方法？
   ★ 不能照搬 W3 的结论 —— 事实 161 说 `CustomPropertyManager` **必须当方法调**，
     而本轮的 `CreateMassProperty` **当属性取就行** ⇒ ★ **同一个父对象的不同成员取法不同**。
② 单位：毫米还是米？
   ★ 不能猜 —— 项目里**已经踩过单位不一致**：`IBody2.GetBodyBox` 实测是**毫米**（官方没写），
     而官方**其余**几何接口惯用**米** ⇒ ★ 只能建一个**已知体积**的盒去问。
③ 负例：在**工程图**上会怎样？
   ★ 不能想当然 —— 本轮实测它**不抛错**（详见下）。
```

## 三、探针设计：**用一个已知体积的盒当"标尺"**

```
建 40 × 20 × 10 mm 的盒 ⇒ 体积 = **8000 mm³** = 8e-6 m³ · 表面积 = 2×(40·20+40·10+20·10) = **2800 mm²**
  ⇒ ★ 读回来跟这两个数比 ⇒ **哪个命中就知道单位**（`volume_matches_mm3` vs `volume_matches_m3`）
  ⇒ ★ 顺带验了**重心**（盒 z 从 −10 到 0 ⇒ 重心 z = **−5**）—— 那是个**独立**的第三个断言。
★ 这种做法（**造一个已知答案的几何**）比"读出来看看像不像"硬得多。
```

## 四、★ 单位与量纲：**一个如实记录的疑点**

```
读数：Volume = 8000（mm³）· Density = 1000.0 · **Mass = 7999999.999999999**
★ 而 **8000 × 1000 = 8,000,000** ⇒ **mass 恰好等于 volume(mm³) × density**
⇒ ⚠ 若 volume 是 mm³、density 是 kg/m³，质量应是 **8 g = 0.008 kg** ⇒ **不是 8e6**
⇒ ★★★ **量纲不成立** ⇒ **mass 的物理单位没有确证**。
★ 处置（本特性的决定）：
   · **照实透传**（它是 SolidWorks 给的数，**不是我算的**）；
   · **工具说明里明写"未确证"**；
   · ★ **不换算、不猜、不给它安一个单位**（不给一个我核不出来的数一个名字）。
```
