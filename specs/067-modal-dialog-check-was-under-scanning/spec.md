# 067 · 查一个「守了每轮收尾」的检查：它在**漏检约 98%**

**Status**: Implemented（轮 148）

## 一、怎么查到的（起因是上轮那个「未查明」）
`066` 留了个「未查明」：`SaveBMP(0,0)`=(1460,1049) vs `SaveAs3`=(1232,1049)，
疑为「窗口 vs 绘图区」。
⇒ 本轮去解它：先找 SolidWorks 的**主窗口**量 `GetWindowRect`。
⇒ ★★ **一找就发现：**
```
PID 20456 的顶层窗口 **49 个，可见的只有 1 个（159x27）**
⇒ **主框架窗口不可见**（SolidWorks 在"无窗口"状态下照常工作：能建模、能截图）
```

## 二、★★★ 由此查出一个真问题
```
我每轮收尾都在跑「查残留模态框」，它的判据是：
    EnumWindows + **IsWindowVisible(h)** + 类名 == "#32770"
⇒ 而 **49 个窗口里只有 1 个可见** ⇒ 那个过滤**漏掉 48 个（约 98%）**
```
⚠ **精确说法不是**「它从未验证过任何东西」——
★ **我第一时间的判断过重了**，查完两个口径的对比数字后改正：
```
默认（不过滤可见性）: #32770 = 0 个 · 扫到窗口 **49** 个
旧口径（只可见）    : #32770 = 0 个 · 扫到窗口 **1** 个
⇒ 它**确实扫到那 1 个**，但**漏掉了 48 个**
```
⇒ **风险面**：那条检查守的是**每轮收尾的安全底线** ——
模态框会把会话**永久挂起**（铁律 2 的头号风险）。**漏检 98% 意味着这条底线基本没兜住。**

## 三、★ 同族的**第三种**形态：「同一个检查被复制 21 份」
```
`tools/` 下有 **21 个文件**各复制了一份 `def modal_dialogs(...)`，
⇒ ★ **没有单一真源** ⇒ 而 21 份里的**每一份都带着同一个错误口径**。
★ 与事实 74/78/79 的「同义词没有单一真源」**同族**，只是这次的载体是**复制的代码**。
```

## 四、处置
```
抽成 **共享**函数 `sw_connect.residual_dialogs(pid, *, only_visible=False)`：
  ① **默认不过滤可见性**（`only_visible` 留作显式选项）；
  ② ★★ **返回 `(dialogs, all_windows)` 两元组** ——
     空列表只有在 `all_windows > 0` 时才有意义（否则分不清「没有」与「没扫到」）。
⇒ 新口径实测扫到 **49** 个窗口 ⇒ **判据不再空转** ✓
```
⚠ **21 份的全量迁移本轮未做**（只做了示范 + 4 条测试）⇒ 其余仍带旧过滤。
