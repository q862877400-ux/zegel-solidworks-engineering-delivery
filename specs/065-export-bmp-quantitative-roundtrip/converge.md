## 三、★★ 本轮真正的方法论收获：**"入参里有没有可回读的量"决定证据强度**
```
弱证据（空操作也能满足）：没抛异常 · 文件存在 · 返回 True
强证据（空操作满足不了）：★ **写进去的尺寸 == 读回来的尺寸**
⇒ ★ 挑任务时**先看官方签名里有没有"可回读的入参"** ——
   有（宽高、角度、直径…）⇒ 能做定量往返；没有 ⇒ 只能找侧证（如边界框、特征树）。
```
★ 这条把 `040`（螺旋线 50mm ⇒ 读回 0.05）· `044`（反向验证）那一族的经验**变成了选任务的准则**。
