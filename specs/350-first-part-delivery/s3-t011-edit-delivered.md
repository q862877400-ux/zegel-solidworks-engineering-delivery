## 四、★★ 我差点记下一个错的结论

第一次跑本探针时，读到「改值生效但**保存重开后变回 100**」，
我一度准备记成「`save_document` 报成功却不落盘」的缺陷。

继续测下去才发现真因是**测量被沙盒改了路径**：

```
文档实际路径：...\output\sandbox\inputs\板1_rev-1_copy__7.SLDPRT
```

`tools/sw_guard.py` 会把输入文件复制到 `output/sandbox/inputs/` 下再交给子进程。
⇒ SolidWorks 打开的是**沙盒副本**，保存也写在那里；
  而我「重开」时又传了**自己那份原始副本**的路径 ⇒ 又拿到一份新沙盒副本（`__N`）
  ⇒ 读到的是**原始内容**，不是保存结果。

**修法**：重开时用 `IModelDoc2.GetPathName()` 读到的**实际路径**，不是我自己传的路径。

修完再跑：`bbox_x: 100.0 → 120.0 → 120.0`、`persisted_after_reopen: True`、
`sha_changed: True`（文件内容真的变了）。

★ 教训：**在沙盒里做「保存 + 重开」这类跨进程验证时，必须用文档自己报告的实际路径，
  不能用调用方传进去的路径**。否则读到的可能是另一份文件。

## 九、孔位联动这条路走到哪了

要让孔跟着板宽走，孔位必须有尺寸/约束绑到板边。本轮试了 3 组选法（都真机）：

| 试法 | 结果 |
|---|---|
| **不选**直接调 H 尺寸（对照） | 尺寸 0 → 0（负例成立：必须先选中） |
| **孔心 + 边线**（点 + 线）→ `AddDimension2` | 尺寸 0 → 0/-1，随后 **SolidWorks 进程崩**（`RPC 服务器不可用`） |
| **孔心 + 角点**（点 + 点）→ `AddHorizontalDimension2` | 尺寸 0 → 0，随后**再崩一次** |

### 为什么会崩

`known-facts.md` **事实 422** 里被验成的那两种选法是：

- **一条线段**（得出该段长度）
- **两个端点**（★ 同一段的两个端点 —— 得到的仍是**该段长度**）

⇒ 它给的是「**选中实体自身的长度**」，**不是「任意两点之间的距离」**。
   我拿「孔心 + 板角」这种跨实体两组点去调，它推不出尺寸 ⇒ 空加或崩。

★ 已按「三次失败就停下质疑架构」停止试选法，不再换组合硬试。

### 下一步的候选设计（未验）

不用「点-点距离」，改用**单段长度**这个已验证能力：

1. 从**右边缘**画一条**构造线**到右侧孔心，孔心与构造线端点重合（`coincident`）
2. 给那条构造线加**水平尺寸**（单段长度 ⇒ 事实 422 验过的选法）
3. 板宽 100→120 时右边缘移动 ⇒ 构造线起点跟着走 ⇒ 孔心随动

★ 这条设计**只用单段长度**，落在已验证的选法范围内，值得下一轮试。
  但它要改 `build_plan()` 的孔生成方式（当前每孔一个草图 + 坐标画圆），
  属于**结构性改动**，需要单独一轮做。
