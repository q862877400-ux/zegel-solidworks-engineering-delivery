## 一、判法（**纯结构**，五条）
```
① 每个 subskills/*/ 有没有 manifest.yaml
② manifest.name 是否**等于目录名**
③ 每个 subskill 是否**进了内嵌快照**（没进就不会随包发布）
④ 快照与源的差异**是否只由缓存构成**（__pycache__ / .pyc）
⑤ 有没有**被 git 跟踪的 .pyc**（铁律 3）
```

## 二、★ 结果：**零发现**
```
subskills/ 5 个目录 · 5 个都有 manifest · 5 个 name 都对得上
```

## 三、★★ 中途一次"**看起来像发现**"—— 以及它是怎么被排除的
```
逐目录比文件数：源 28/15/26/8/14  vs  快照 19/11/19/7/12
⇒ **5 个全不一致，合计少 23 个**  ⇒ 那一刻看起来像"漏发了 23 个文件"
★ 但**先查同步脚本的收录规则**（SKIPPED_DIRECTORIES 含 __pycache__、
  SKIPPED_SUFFIXES 含 .pyc）⇒ 再**逐条列出差异**
⇒ **23 个全是 `__pycache__/*.pyc`** ⇒ ★ **同步脚本排除得对，不是 bug。**
```
★ 教训（与 `057` 那次"实验错 vs 判据错"同族）：
**数字不一致只是"要去看"的信号，不是结论** —— 必须把差异**逐条列出来**再判。
