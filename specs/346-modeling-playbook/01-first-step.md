# 第一章 · ★★ **拿到图纸，第一步做什么？**

**★ 级别**：`stitched` ✗（★ 讲义提取，★ 未真机验证 ✓）
**★ 本章回答**：★ 在**碰任何命令之前**，脑子里该先跑哪几步 ✓

---

## ★★ 一句话结论（★ 先看这个 ✓）

```
★★ 【先定"整体是什么"，再决定"怎么减出来"】✓
★ 顺序：★ ① 认视图 → ② 定整体 → ③ 数清"哪些块是空的" → ④ 再动手
★★ 反例（★ 错的）：★ 拿到图纸就开始逐块拼 ✗
```

---

## ★ 第一步：**认视图 —— 逐张标出"从哪往哪看"**

★ **出处**：★ `P11` [00:03]–[00:36] ✓（★ 见 [`p11-basic-geometry-practice.md`](../345-video-lectures/p11-basic-geometry-practice.md)）

★★ **判据**：★ **不要硬猜** ✗ —— ★ 逐张在图上**标出"从这边往这边看"** ✓
★ 作者原话：★「**我怎么看不懂啊**」「来 我们**来标记一下**」「**从这边往这边看**图」✓
★ 三视图看不过来时：★ **作者的做法是"标记 + 擦掉"** ✓ —— ★ **这是理解手段、不是建模步骤** ✓

---

## ★★ 第二步：**定整体 —— "它的整体是一个长方体"**

★ **出处**：★ `P11` [00:47]–[01:18] ✓

★★★ **这是全手册最重要的一条** ✓：

```
★ 作者的原话链（★ 逐字）：
  ★「首先是这一块」→「它是不是一个**长方体**啊」
  →「这一块是不是一个**长方体**」→「这里 **两个长方体**」
  →「第三个面呢」→「是一个**缺口的长方体**」
  ★★→「说明什么 **它的整体是一个长方体**」
  ★★→「然后**一步一步的切**啊」
```
★★ **读法**：★ 三视图里**每一块都能被"整体 + 缺口"解释** ⇒ ★ **整体定了** ✓
★★★ **判据**：★ **空的那块在图纸上是画出来的**（★「这边是**空的**」「**尺寸都给你了**」✓）
⇒ ★ **能减就减，别拼** ✓

---

## ★★★ 第三步：**数清"要切几刀"** —— 并接受"不一定一口气"

★ **出处**：★ `P11` [01:26]–[01:38] ✓

```
★ 作者遇到切不出来的形状：★「这个好像**不能一口气切出来**」
★★ 心态（★ 逐字）：★「那我们可以**两口气**啊」「我们**不一定非要一口气**啊」
★ 但也提示：★「当然它也**有一口气的方法**」⇒ ★ 后面演示（★ 放样切除 ✓）
```

★★ **判据**：★ **先按"几刀"规划** ✓ —— ★ **不要求一次成型** ✗
★ 想一步到位时：★ 查第二章「放样切除」✓

---

## ★★ 第四步：**曲面类零件 —— 换成"找边界线"**

★ **出处**：★ `P23` [17:54]–[18:36] ✓（★ 见 [`p23-surface-spoon.md`](../345-video-lectures/p23-surface-spoon.md)）

★★★ **曲面不能用"整体减"的思路** ✗ —— ★ 要用**边界线** ✓：

```
★★ 曲面建模通用流程（★ 作者逐字）：
   ① 【看视图找边界线】—— ★ 正面 / 辅助 / 侧视（★ 本集"没给侧视"⇒ ★ **只看两张图** ✓）
   ② 【认清每条线"对应什么"】—— ★ 例如"这条线对应外圆 / 底边的外面这个" ✓
   ③ 【把几条边界线画出来】
   ④ 【再进行曲面建模】⇒ ★ **勺子就出来了** ✓
```
★★ 作者的定心话（★ 逐字）：★「**不要想的那么难**」「**曲面没有那么难的**」
★「**只是说你要有经验而已**」✓

## ★ 第六步：**先画定位，再画别的**

★ **出处**：★ `P23` [09:13]–[09:16] · `P34` [00:16]–[00:18] ✓

★★ **判据**：★「**先画什么? 先画定位**」「定位好，之后我们**再看怎么画它**」✓
★ 钣金的角撑板同理：★ 位置 = **「面面边点」**（★ 两个面 + 一条边 + 一个点 ✓）
