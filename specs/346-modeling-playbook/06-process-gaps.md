**★ 级别**：`stitched` ✗（★ 讲义提取，★ 未真机验证 ✓）
**★ 本章回答**：★ 哪些地方**必须留间隙**、**留多少**、**为什么** ✓
★★ **本章的价值**：★ 这些值此前**散在 5 讲、从没同表** ✗ —— ★ 而且**理由都是工艺性的** ✓

---

## ★★ 一句话结论

```
★★ 【留间隙不是为了好看，是为了"装得进去 / 压不坏 / 折不出伤"】✓
★ 三类理由：★ ① **要插进去**（不留就插不进 ✗）② **要压/折**（不留就损坏 ✗）
             ③ **要展开**（不留就伤边 ✗）
★★ 反例（★ 错的）：★ 理论零间隙 = 做出来能装配 ✗
```

## ★★★★★ 间隙一：**薄片与槽口 —— 0.1**（★ 理由最直白 ✓）

★ **出处**：★ `P35` [03:42]–[04:00] ✓（★ 见 [`p35-sheet-metal-tab-slot.md`](../345-video-lectures/p35-sheet-metal-tab-slot.md)）

★★★ **作者逐字**：
```
★「0.1 是什么」「**是间隙**」
★「我们**为什么要有间隙**」
★「因为我们在**生产制造的过程中**」
★「如果说你**没有留间隙的话**」「它就**插进去了**」
★「**插不进去呢**」「我们**做这个干嘛**」
★「所以我们**要留一个间隙**」
★「**不然它整个板插不进去了**」
★「那**做这个板就没有意义了**」
```
★★★ **定则**：★★ **薄片是要【插】进槽里的** ✓ ⇒ ★ **零间隙 = 插不进 = 这个特征白做** ✗

## ★★★★★ 间隙二：**边线法兰 —— 0.5**（★ 理由在"展开"✓）

★ **出处**：★ `P25` [07:37]–[08:16] ✓（★ 见 [`p25-sheet-metal-edge-flange.md`](../345-video-lectures/p25-sheet-metal-edge-flange.md)）

★★★ **作者逐字**：
```
★「這個尺寸是**他們之間的一個縫隙的距離**」
★★「**一般默認的話**」「**0.5 差不多了**」（★ 试过 1 / 5 / 8 ✓）
★「我們**為什麽要留這個呢**」
★「就**跟那個四胖（释放槽）草（槽）一樣的**」
★★「你這個**什麽展開折疊的時候**」「**容易損傷到這個邊**」
★「所以我們**還是要留縫隙的**」
```
★★ **注意**：★ 作者**主动把它和释放槽归为一类** ✓ —— ★ **同一族理由：工艺间隙** ✓

## ★★★★★ 间隙三：**钣金释放槽 —— 默认自动切**（★ 理由在"压"✓）

★ **出处**：★ `P24` [01:57]–[02:32] ✓（★ 见 [`p24-p34-sheet-metal.md`](../345-video-lectures/p24-p34-sheet-metal.md)）

★★★ **作者逐字**：

```
★★「我们会在**钣金这个压的过程中**」「**这里会损坏**」

★★「一般来说我们**直接让它保留就行了，自动切槽就行了**」
```
★★ **判据**：★★ **默认「自动切释放槽」就行** ✓ —— ★ 不用手动加 ✗

## ★★★★ 间隙五：**褶边撕裂型角度 —— 不能 180**（★ 这是"限制"不是"间隙"✓）

★ **出处**：★ `P27` [01:47]–[03:01] ✓（★ 见 [`p27-sheet-metal-hem.md`](../345-video-lectures/p27-sheet-metal-hem.md)）

★★★ **作者逐字**：
```
★「**它不能调到 180**」「我们**输入 180 看一下**」
★「就给你谈（弹）一个什么」「**180 到 270 之间的度数**」
★ 为什么：★「它的这个**条边**」「**没法跟我们的这个面相接**」
          ★「它是不是这个**弯下来的**」「这个线是**直接跟这个面相交**的」
          ★「**还如果不相交**」「它就**无线延伸**」
⇒ ★「**所以是不可以生成 180 度的**」
```
★★ **实测可用值**：★ **190** · **250** ✓ · ★ 半径 **1 / 0.5** ✓

## ★★ 附：**K 因子**（★ 不是间隙，但同属"工艺参数"✓）

★ **出处**：★ `P24` [01:22]–[01:56] ✓

★★ **作者逐字**：
```
★★「**K 因子就是我们的这个【里面这一层】到【中性层】的距离，
     除以我们这个【整个板材的厚度】】**」
```
★★ **公式**：★ `K = (内表面到中性层的距离) / 板厚` ✓ · ★ **界面默认 `0.5`** ✓
⚠ ★★ **本仓另有记录说"实测有三处不一致的默认值"** ✗ —— ★ 那是**本仓的实测**，
★ 不是视频讲义说的 ⇒ ★ **本章不混入** ✓（★ 详见 `corpus` 里对应条目 ✓）

## ★★ 三类理由的归纳（★ 本章的"为什么"✓）

| ★ 理由 | ★ 场景 | ★ 例子 |
|---|---|---|
| ★★ **要插进去** | ★ 两个零件要**互插** | ★ 薄片与槽口（★ 0.1 ✓）|
| ★★ **要压/折** | ★ 钣金**成形过程**有挤压 | ★ 释放槽（★ 自动 ✓）· 边角释放槽 |
| ★★ **要展开** | ★ 展开/折叠时**边会受伤** | ★ 边线法兰缝隙（★ 0.5 ✓）|

★★★ **共同点**：★★ **理论零间隙 = 做出来装不上 / 会坏** ✗ —— ★ **加工有公差** ✓
