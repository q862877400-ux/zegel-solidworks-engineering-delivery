# 第三章 · ★★★ **工序谁先谁后？**（★ 什么必须排最后）

**★ 级别**：`stitched` ✗（★ 讲义提取，★ 未真机验证 ✓）
**★ 本章回答**：★ 同一堆特征，**按什么顺序做才不会返工** ✓
★★ **这是最容易做反的一层** ✗ —— ★ 做反了往往不是"报错"，而是**后面根本没法做** ✗

---

## ★★★ 一句话结论

```
★★ 【会"占用几何"的操作排后面；"减掉几何"的操作排最后】✓
★ 顺序：★ ① 先建"要用的几何" → ② 再加"依赖它的特征" → ③ 打孔 → ④ **最后才切**
★★ 反例（★ 错的）：★ 先把缺的块切掉、再去做依赖那块几何的特征 ✗
```

## ★★★★★ 纪律一：**切要留到最后**

★ **出处**：★ `P16` [02:46]–[02:57] ✓（★ 见 [`p16-handle-modeling.md`](../345-video-lectures/p16-handle-modeling.md)）

★★★ **作者逐字（★ 理由说得很清楚 ✓）**：
```
★「我们在这里**先不要急着切**」
★「我们**放到最后**以防」
★「到时候**你们这边新建了**」
★「之后怕**先把这个缺的部分**」
★★「**已经切掉的部分给它占掉了**」
★「所以我们**最后再切**」
```
★★ **机制**：★ 后面新建的草图/特征，**要基于"那块还在的几何"** ✓
⇒ ★ **先切掉 ⇒ 它就没地方放了** ✗

## ★★★★ 归纳：**一张"什么必须排最后"的判定表**

★★ **判定规则**（★ 从上面两条归纳 ✓）：
```
★ 问自己：★ "我这个特征，是【**吃掉**】某块几何，还是【**用**】某块几何？"
   · ★ **吃掉**（切、剪、断开）⇒ ★★ **排最后** ✓
   · ★ **用**（贴面、投影、实体引用、孔、倒角）⇒ ★ **排在它依赖的几何之后、切除之前** ✓
```

| ★ 操作 | ★ 吃 / 用 | ★ 该排在哪 |
|---|---|---|
| ★ **拉伸切除 / 剪裁** | ★ **吃掉** ✗ | ★★ **最后** ✓ |
| ★ **孔 / 异型孔向导** | ★ 用（依赖面） | ★★ **后面**（★ 但**在切除之前** ✓）|
| ★ **倒角 / 圆角** | ★ 用（依赖边） | ★ 后面 ✓ |
| ★ **镜像 / 阵列** | ★ 用 | ★ 在被镜像的对象之后 ✓ |
| ★ **实体引用 / 投影曲线** | ★ 用（依赖已有线/面） | ★ 在源几何之后 ✓ |
| ★ **斜接 / 边线法兰** | ★ 用（依赖已有钣金边） | ★ 在基体法兰之后 ✓ |
