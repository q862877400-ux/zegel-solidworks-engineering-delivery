## ★★ 一句话结论

```
★★ 【"软件能不能点下去"不是判据；"生产规范 / 专业分工"才是】✓
★ 三条边界：★ ① 大量快速出图 ⇒ **CAD** ✗ ② 做曲面 ⇒ **专门软件** ✗

```

★ 另一处（★ 更具体）：★「**真要学的话还是用中二 CD（AutoCAD）**」✓

★★★ **判据（★ 划得很清 ✓）**：
