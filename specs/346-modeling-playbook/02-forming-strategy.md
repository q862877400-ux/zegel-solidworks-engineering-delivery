# 第二章 · ★★ **整体怎么成型？**

**★ 级别**：`stitched` ✗（★ 讲义提取，★ 未真机验证 ✓）
**★ 本章回答**：★ 已经知道"整体是什么"之后，**用哪种方式把它做出来** ✓

---

## ★★ 一句话结论

```
★★ 【先看"截面"能不能转，再看"轮廓能不能扫"，最后才想"怎么切"】✓
★ 顺序：★ ① 截面是圆/回转体 → 用【旋转】 · ② 有轮廓 + 路径 → 用【扫描/扫描法兰】 ·
       ③ 钣金件 → 先【基体法兰】 · ④ 曲面 → 【边界线】+ 填充/放样 · ⑤ 都不是 → 【拉伸 + 逐步切除】
★★ 反例（★ 错的）：★ 一上来就拉伸一个方块然后拼命切 ✗
```

---

## ★★★★ 判据一：**判"能不能用回转" = 看截面是不是圆**

★ **出处**：★ `P15` [00:27]–[00:35] ✓（★ 见 [`p15-lock-nut.md`](../345-video-lectures/p15-lock-nut.md)）

★★★ **这是本手册里最干净的一条判据** ✓：

```
★★ 作者逐字：★「说明什么 这里是这里 **它就不是个圆**」
            ★「然后**这里才是圆**」
            ★★「这样我们就**不能直接用回转的方式来构建它**」
            ★★「**必须要一层一层建**」
⇒ ★★ 定则：★★ **截面只要有一段不是圆 ⇒ 不能用回转** ✗ ⇒ ★ **必须一层一层建** ✓
```

★★ **判法**：★ 沿轴线看，**每一段截面的轮廓是不是都以轴为中心的正圆** ✓
★ 有一处不是（★ 例：六角、方、扁）⇒ ★ **回转不适用** ✗

---

## ★★★ 判据二：**回转体的做法 = 中心线 + 轮廓**

★ **出处**：★ `P16` [00:51]–[08:10] ✓（★ 见 [`p16-handle-modeling.md`](../345-video-lectures/p16-handle-modeling.md)）

```
★ 作者逐字：★「首先是一个轴 **它是个对称图形**」
           ★「然后这里是个**回转梯（回转体）**」
★★ 做法：★ 画【**中心线**】+ 轮廓 ⇒ **旋转** ✓
★ 本集尺寸链（★ 可当样例）：★ 14 / 4 / 16 / 13×2 / 30 ✓
```

★★ **配套三条手法**（★ 同一集 ✓）：
```
① ★★【实体引用】= ★ 把已有几何的线**引到新草图里用**（★ 不重画 ✓）
② ★ 配合约束：★ **相切 / 镜像 / 剪掉多余部分** ✓
③ ★ 拉伸两种终止：★ **反向 + 到面** ✓ · ★ 或 **给定深度** ✓
```

---

## ★★★ 判据三：**扫描 = 轮廓 + 路径**

★ **出处**：★ `P30` [00:26]–[00:46] ✓（★ 见 [`p30-sheet-metal-swept-flange.md`](../345-video-lectures/p30-sheet-metal-swept-flange.md)）

```
★ 作者逐字：★「我们先点击**扫描** 看一下**它需要什么**」
           ★★「**一个轮廓 一个路径**」
```
★★ **判据**：★ 有一个**要沿着的路径** + 一个**要扫过去的截面** ⇒ ★ 用扫描 ✓

---

## ★★★ 判据四：**钣金 = 先基体法兰，再加法兰/折弯**

★ **出处**：★ `P25` [00:02]–[00:28] · `P26` [00:00]–[00:08] · `P28` [00:04]–[00:09] ✓

```
★ 边线法兰：★「在使用邊線法欄這個指令之前」「**先生成一塊板**」✓
★ 斜接法兰：★「先建立我们的**基地（基体）法栏**」✓
★★ 转折：★「这个**转折这俩同样是灰的**」⇒ ★ 按钮**是灰的、点不了** ✗
```
★★★ **定则**：★★ **所有钣金命令都挂在"已有钣金"上** ✓ —— ★ 不能从零开始 ✗
★ **例外**：★ 别人给的实体 ⇒ ★ 用【**转换到钣金**】变成钣金（★ `P31` ✓）

---

## ★★★ 判据五：**曲面 = 找边界线，不是"整体减"**

★ **出处**：★ `P23` [17:54]–[18:36] ✓（★ 见 [`p23-surface-spoon.md`](../345-video-lectures/p23-surface-spoon.md)）

```
★★ 曲面建模通用流程（★ 作者逐字）：
   ① 【看视图找边界线】—— ★ 正面 / 辅助 / 侧视（★ 本集"没给侧视"⇒ ★ **只看两张图** ✓）
   ② 【认清每条线"对应什么"】—— ★ 例如"这条线对应外圆 / 底边的外面这个" ✓
   ③ 【把几条边界线画出来】
   ④ 【再进行曲面建模】⇒ ★ **勺子就出来了** ✓
```
★★ 作者定心话：★「**不要想的那么难**」「**曲面没有那么难的**」「**只是说你要有经验而已**」✓

★★ **曲面两条专属纪律**（★ 同一集 ✓）：
```
① ★★ 两条斜边【**不能画在同一张草图上**】✗ —— ★ 曲面命令选一条边时会把另一条也算上
   ⇒ ★「会把这两条线**认成一个断面**」⇒ ★「**形成不了一个曲面**」✓
② ★★ 填充曲面的策略：★ **先建一片占位**（★「它**只形成了上面的这一片**」「**不着急**」✓）
   ⇒ ★ 再**逐条线分割**、★ 用它定位 ✓
```

## ★★★ 判据六：**一步到位 = 换方向 + 【放样切除】**

★ **出处**：★ `P11` [04:49]–[05:25] ✓（★ 见 [`p11-basic-geometry-practice.md`](../345-video-lectures/p11-basic-geometry-practice.md)）

```
★ 作者逐字：★「我们**不往从前往后切**」「**我们先从上往下切**」「同样也是**可以的**」
           ★「我们有一个**一步到位的方法**」「来 我们点击这个**放样切除**」
★★ 注意（★ 作者亲述的坑）：★「它现在**没有生成一个我们需要的面**」✗
   ⇒ ★ **就移动它、把它移下来** ✓ ⇒ 确认 ⇒ 一步到位 ✓
```

## ★★ 本章的一张决策表

| ★ 你看到 | ★ 该用什么 | ★ 出处 |
|---|---|---|
| ★ **截面全是圆（回转体）** | ★ 【**旋转**】（★ 中心线 + 轮廓 ✓）| ★ `P15` · `P16` |
| ★ **有一段不是圆** | ★★ **不能用回转** ✗ ⇒ **一层一层建** | ★ `P15` |
| ★ **有轮廓 + 路径** | ★ 【**扫描**】 | ★ `P30` |
| ★ **钣金件** | ★ **先基体法兰** ⇒ 再加法兰/折弯 | ★ `P25`/`P26`/`P28` |
| ★ **别人给的实体** | ★ 【**转换到钣金**】 | ★ `P31` |
| ★ **曲面零件** | ★ **找边界线** ⇒ 填充/放样曲面 | ★ `P23` |
| ★ **切不出来的怪形状** | ★ **换方向切** 或 **放样切除** | ★ `P11` |
| ★ **以上都不是** | ★ 拉伸 + 逐步切除（★ 第一章的"整体减"）| ★ `P11` |
