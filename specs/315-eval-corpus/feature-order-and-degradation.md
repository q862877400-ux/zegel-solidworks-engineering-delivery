## §1 ★★ 特征顺序（★ 直接可用）

**来源**：该文件 L122「推荐特征顺序」（用于 CNC 安装座、连接块、机加工基座）

```
1. 基础矩形底板拉伸
2. 顶部凸台拉伸
3. ★★ 外轮廓大圆角和顶/底边倒角      ← ★ 在孔槽之前！
4. 减重口袋
5. 贯穿安装孔
6. 沉孔/沉头台阶
7. 定位孔
8. 中心长圆槽
9. 孔口小倒角
10. 保存、导出 STEP、审查预览
```

**★★★ 关键判据（逐字）**：

> 如果步骤 3 放在**孔槽之后**，SolidWorks 可能在**复杂拓扑上求解很久**。
> 若必须后置，先**减少半径、减少边数，逐类测试**。

**⇒ 这改变我的做法**：★ 我的 `L3-002/006/007` 都是「先建主体 → 再倒角」，
★ 而**大圆角/外轮廓倒角该在孔槽之前**。

## §2 ★★ 半径降级策略（★ 有具体数值）

**来源**：该文件 L139「半径和降级策略」

**保守默认值**（逐字）：

| 位置 | 推荐值 |
|---|---|
| 底板立角大圆角 | **R6–R10** |
| 凸台立角圆角 | **R3–R6** |
| 外轮廓倒角 | **C0.8–C2** |
| 凸台顶面倒角 | **C0.5–C1** |
| 孔口倒角 | **C0.3–C0.8** |

**★★ 两种策略**：
- `strict`：只试请求尺寸，**失败即停**（★ 适合尺寸不可协商的图纸交付）
- `progressive`：依次试 **100% / 75% / 50%**，**最小不低于 0.1 mm**

**★★★ 而 `progressive` 不是静默修复**（逐字）：

> 参数 JSON 必须同时记录 `requested_value_mm`、`actual_value_mm`、
> 状态 `degraded` 和每次失败信息；**对外说明必须使用实际尺寸**。

**⇒ 这正好补上我 §4 那条缺口**（★ 我说「倒角失败要降级」，★ 而**降级的具体做法这里有**）。

## §3 ★★ 人工排障顺序（★ 5 步，逐字）

```
1. 减小半径/倒角距离
2. 减少一次选择的边数
3. ★ 把大圆角前置到孔槽之前
4. 若用户允许，显式把非关键槽口/口袋圆角设为 0 后重新生成计划
5. ★★ 关键圆角或倒角不得自动跳过；无法满足时保持阻断
```

**★★ 第 5 条是关键**：★ **关键**的不能跳、**非关键**的可以设 0 ⇒
★ 而**谁关键谁不关键**要**标明**（★ 不能一律降级）。

## §4 ★★ 判据（★ 逐字，可直接用）

> 特征 API **返回非空后仍需 `ForceRebuild3(False)`**，并用**特征名从树中回读**。
> **返回 `None` 才允许进入下一档尺寸**；
> ★★ **若返回非空但重建后特征消失，应停止而不是继续叠加新特征。**

**★★ 这是一条我没想到的判据**：★ 「返回非空」**不等于**「重建后还在」。
