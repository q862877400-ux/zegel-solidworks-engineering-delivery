# 020 · 人工核样：「后缀候选 144」的真实命中率只有约 25%

**Status**: Implemented（轮 101）

## 背景
目标 ② 是「B 级并入 339 个缺口操作」。`010` 的分诊把缺口分成四档，其中最大的一档是
「**能力在、未暴露**：**144** 条（42%）—— `scripts/sw_*.py` 里有同名函数，只是没暴露」。
⚠ **该归类来自字符串（后缀词）匹配**，而它标着「需人工核」。

## 抽查一眼就不对
```
arc            -> sketch_arc          ✅ 同一操作
assembly       -> dissolve_assembly   ❌ 「分解装配体」不是「装配」
broken_view    -> call_view           ❌ 「断裂视图」不是「调用视图」
apply_template -> find_template       ❌ 「应用模板」不是「查找模板」
```

## 做法
**人工核样 24 条**（对 144 条**每 6 取 1**，规则可复算），逐条判 真 / 部分 / 假。

## 结果
```
✅ 真 **6**  ·  ⚠ 部分 **2**  ·  ❌ 假 **16**
⇒ 真实命中率 ≈ **25%**（24 个样本，95% 区间约 12%~43%）
```

## ★★ 结论：那一档**高估了**
```
原分档：能力在未暴露 144（42%） · 真缺 132（39%）
按 25% 折算：真匹配 ≈ **36** · 假匹配 ≈ **108**（应归进"真缺"）
⇒ 真缺 ≈ 132 + 108 ≈ **240**（不是 132）
```

★ **根因**：该档按**后缀词**匹配，而 `sketch` / `view` / `template` / `macro`
在 SolidWorks 里是**高频通用词** ⇒ 一个 `*_view` 就能配上几十个操作。
⚠ **这与已知事实 52（名字是弱信号）同源** —— 这一档**不该由字符串匹配给结论**。
