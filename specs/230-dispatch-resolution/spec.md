# spec 230 · 分发口「解析面」—— 调用点可静态解析性的门禁

> 特性目录：`specs/230-dispatch-resolution/` · 建立：2026-10-09（主任务 `ff6c7344` 第 4 轮）
> 上游：`specs/229-dispatch-entry-guard/`（分发口守卫覆盖门禁）登记的**下一 WIP ①**。

## 一 · 为什么要做

229 把 **37 个分发口**逐个表态，但 `exempt *` 的语义只是「**已知盲区、登记在案**」。
229 的未过门 ① 写着：**36 个被豁免入口的 by-ref 占位仍未核**。
要核，先得回答一个**没人量过**的问题：

> 这些分发口的**调用点**，能不能**静态解析出成员名**？

能解析 ⇒ 那个调用点就等价于一次「成员名写在调用点」的调用 ⇒ **可以继承
`audit_byref_args` / `audit_call_arity` 的判据**。不能解析 ⇒ 只能继续登记为盲区。

## 二 · 需求（每条带来源与许可）

| # | 需求 | 来源 | 许可 |
|---|---|---|---|
| FR-1 | 门禁必须**按文件作用域/限定名**索引分发口的调用点（同文件裸名 · 跨文件 `from <模块> import <名>` · `模块.名`），**不得**按裸名索引 | 229 教训：`_checked` 在 9 个模块重名，裸名索引把调用点合并成 94 ⇒ 分类被假命中污染 | 本仓库 MIT |
| FR-2 | 每个分发口必须被归入**解析类**之一：`resolved` / `partial` / `unresolved` / `no-callers` | 本轮量测 | 本仓库 MIT |
| FR-3 | **一级转发**才算可解析：内部包装调用第 2 位起的每个实参槽必须是「形参 / `*形参` / 固定表达式」；出现 `*局部变量` ⇒ `unresolved` | `sw_simulation_loads._check` 的 `*tail`（局部 list） | 本仓库 MIT |
| FR-4 | 解析类计数与可解析调用点数**冻结下界（只增不减）** | 229 既有纪律：减少 = 探测器漏了 | 本仓库 MIT |
| FR-5 | **假绿守卫**：下界非 0 而可解析调用点为 0 ⇒ FAIL（解析器失效不许 PASS） | 事实 46 | 本仓库 MIT |
| FR-6 | 门禁**只分类、不判罪** —— 成员名的 arity / by-ref **约定**必须**由人写死**，门禁不得自动挑选 | spec 227 教训 | 本仓库 MIT |

★ **不做**（明确划界，见 §四）：把解析出的成员名接进 `audit_byref_args` —— 那是 **spec 231**。

## 三 · 契约

`scripts/check_dispatch_entry_guard.py` 新增**解析面**读数（与 229 的声明面并存）：

```
★ 解析面（按文件作用域索引调用点）：resolved 18 · partial 3 · unresolved 4 · no-callers 12 · 可解析调用点 327
```

| 类 | 定义（纯语法、约定无关） |
|---|---|
| `no-callers` | 文件作用域内**找不到**调用点 |
| `resolved` | 有调用点，且**每一个**都能解析出**字面量**成员名（含一级转发） |
| `partial` | 有调用点，**部分**能解析 |
| `unresolved` | 有调用点，**一个都解析不出**（含非一级转发） |

**下界**（真树实测 · 2026-10-09）：`resolved ≥ 18` · `可解析调用点 ≥ 327`。
`DSH_DISPATCH_BASELINE_MIN` 支持 **3 值（旧口径，解析面取 0）** 或 **5 值（含解析面）**
⇒ 229 的合成树判据**不受影响**（向后兼容）。

## 四 · 未过门（★ 不许冒充通过）

1. ★★ **解析出的成员名还没有接进 `audit_byref_args`** —— 本切片只把「可解析」这件事
   **量出来并冻结**；`resolved` 的 18 个入口的 by-ref 占位**仍未核**。⇒ spec 231。
2. `partial` 3 个 · `unresolved` 4 个 · `no-callers` 12 个**仍无任何运行期证据**。
3. **别名导入未覆盖**（`import sw_a as x` 后 `x._d(...)`；`from sw_a import _d as f`）。

5. `*局部变量` / 计算式成员名**一律判不可解析**（二级数据流不做）。
