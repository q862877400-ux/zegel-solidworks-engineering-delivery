token ≈ 字符 / 3.5

## 三 · ★★ 纯机械步：**这几步不许派 agent**

| 步 | 为什么它是纯机械 | 派了会怎样 |
|---|---|---|
| **⓪** | 读 129 个已存在的 JSON、复现 6 个比例 | ★ 派 N 路 agent 去「读一遍」= 把**可复算的算术**换成**不可复算的转述** |
| **⓪′** | 跑 `len(rc.all_specs())` 与两个正则 | 同上；且**引入第二轮口径漂移** |
| **①** | `ToolSpec.module/function` 是**显式字段**（`module="sw_topology"` 之类）⇒ **零解析**；`api-map §二` 是**已生成**产物 ⇒ JOIN 是秒级 | ★★ `FRAMEWORK §7b.10` 逐字：**派 agent 是纯浪费**。★ 把它派成 N 路 agent 去「读能读到的函数」**不是 ①** —— 那是**重做一遍 `api-map`**，反而**降低可复算性** |
| **①′** | 目录计数 + 字符串解析（`## Description`） | 同上 |
| **②a** | 集合交集 + `argmax` + 固定 tie-break | ★ 这是**判据的定义**；用 LLM 算它 = 把可复算的东西交给不可复算的东西 |
| **③a** | 池构造 + 五条断言 | ★ 断言必须由**脚本**保证（`assert`），LLM 的「我检查过了」不构成断言 |
| **③b** | 本地 BM25（`metric_scope.bm25_topk` 同族） | 零 LLM 成本，且**必须同条件** ⇒ 换实现就毁了「同条件」 |
| **④** | 按 `spec.md §五` 七行查表 | ★ 判决必须是**写死的规则**执行的结果；★ 目视认定拐点**是作弊**（`spec.md` 9.2-B5/B6） |

★ **一句话**：**机械步用 `python` 跑，把 `stdout` 与产物落盘；判据是断言与文件，不是 agent 的话。**

## 四 · ★★ 最便宜的可否证版（L0）与它到底能掉什么

| 项 | 设定（故意取最小） |
|---|---|
| 任务 · W 点 | **40** 条（`H` 20 + `L` 20，固定 `SEED_MAIN = 207`）· 只有 **2 个 W：10 与 433** |
| ★ 池 | **Arm-α 锚定池**（`gold ∈ C(10)`）。★ 若用随机池，`W=10` 时 `pool_coverage ≈ 10/433 ≈ 2.3%` ⇒ `p(10)` 恒 ≈ 0 ⇒ **那一版其实测不出东西**（这是对 D 版的**关键修改**） |
| 模式 · 链 · 路数 | **M1（index）**（唯一能跑到 `W=433` 的）· **1 条链** · **1 路** |
| 成本 | **80 次调用 · 1.20 M 字符 · ≈0.34 M token · 免费档 0 元 · 墙钟 < 30 min** |
| 观测量 | `p_strict(10)` · `p_strict(433)` · 配对 `Δ` 的 95% CI · `p_noleak` · `abstain_rate` |

| 问 | 答 |
|---|---|
| 能不能**确认**「架构值得建」？ | ★ **只能**在**效应极大**时：`n=40` 时 Wilson 半宽 `[复算]` ≈ **±15pp** ⇒ 只有 `Δ ≳ 25–30pp` 才是「几乎不可能看错」的信号 |
| 能不能**否决**架构（= 得出「不需要路由」）？ | ★★ **不能**。B 的检出下限 ≈ **180 配对**（`Δ=0.10`、`π_d ≈ 0.25`）⇒ `n=40` 的检验功效远不够；**`CI` 含 0 在 `n=40` 时是默认结果，不是证据** |
| 那它有什么用？ | ★ 三个正当用途：① **筛掉「连 10 个都挑不准」**（`p(10) < 0.70` ⇒ 直接出 **F-B**：这是真否决，否的是**路由这条路**，不是 W 效应）② 抓**泄漏 / `abstain` 超限 / 池坏**这类「一票作废」故障（小样本就看得见）③ 给 **L1 / L2 定预算** |
| 谁能真正否决？ | ★★ **L1（200 题 × 2 点）**：`CI` 含 0 且 `p(433) ≥ 0.85` ⇒ **F-A**；含 0 且 `p(10) < 0.70` ⇒ **F-B**；含 0 且 `0.70 ≤ p(10)` 且 `p(433) < 0.85` ⇒ ★★ **F-C（第四种：减少 / 合并工具）** |
| 落地顺序 | ★★ **L0（<30 min）→ L1（~1 h）→ L2 + L2′（3–5 h）**；**L0 没否掉「路由这条路」时，L1 才有资格谈 W**；**只有 L1 也没给出 F-A / F-B / F-C 时，才投 L2 定 `W*`** |

## 五 · 派活纪律（★ 该派与不该派的分界）

| 情形 | 派不派 | 规定 |
|---|---|---|
| AST 解析 / JOIN / 映射 / 汇总 JSON / 查表判决 | ❌ **不派** | 秒级的事 |
| ★ **「示例 → 能完成它的工具」的判断** | ✅ **该派** | 但那是**判断**，要**带引文闸 + 多路一致率 + 独立裁判**，**不是散弹** |
| ★ **分类 / 路由测试（③c–③g）** | ✅ **该派** | **必须多路取一致率**（免得把单路偶然当结论）＋ **1 路独立裁判** |
| 代理抽检（②b） | ✅ **该派** | ★ **Bunny 唯一该被派的地方**；抽检必须**朝假阴性倾斜** |

### 5.1 路数与模型（逐条落定）

| 角色 | 用什么 | 硬约束 |
|---|---|---|
| **被判路（③c–③g、②b）** | ★ **便宜档 / 免费档**（本仓可用的免费模型族） | 一路一份（**不合并**）· 一波 `≤ 60` 路 · 先 **5 路探针** 再放量 · `returned: 0` **当失败查**（不重试同一进程） |
| **裁判（②b、③c、③e）** | ★ **另一个模型族**（**必须 ≠ 被判路那一族**） | 裁判**看不到**成员表 / 官方 `category` / `## Postconditions` / 代理答案 |
| **⓪″（补记 prompt）** | 便宜档亦可（判读型，1 路） | 答不出 ⇒ **只许 `UNDECIDABLE`**，不许猜 |
| **出规格 / 写脚本 / 改门禁** | ★ 主力模型 | ⚠ **本规格的机械步不需要它**；它只用于「写脚本」与「读产物」 |

### 5.2 ★ prompt 纪律（照抄 204 / 206 的教训）

| # | 纪律 |
|---|---|
| PR-1 | 提示模板 / 答案格式 / `NONE` 提供与否，在 **7 个 W 上逐字相同**，且**模板落盘**（可 `prompt_hash` 复算） |
| PR-2 | 每次调用落盘 `{task_id, W, seed, prompt_hash, shown_order, answer, model}` |
