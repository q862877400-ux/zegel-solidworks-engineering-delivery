# 207 · `p(W)` 曲线实验 · **可派活任务清单**

> **本文件是什么**：把 `plan.md` 的步骤链拆成**逐条可派活的任务**。每条给：**编号 · 一句话 · 输入 · 产出文件 · 判据 · 要不要 agent · 依赖**。
> ★ **纪律**：**机械任务派 agent 是纯浪费**（`FRAMEWORK §7b.10` 逐字）。机械任务**只许**由 `python` / `pwsh` 跑，判据是**断言与文件**，不是 agent 的话。
> ★ 本文件**不改任何主线文件**；无行号；`[复算]` = 本次亲自重算，`[转引]` = 只来自 M1 / M2 / FRAMEWORK，`待测` = 谁都没有的数。
> ★ **不许编数字**：没数的位置写 `待测`。
> ★ **依赖是硬序**：`T-xx` 未完成前不许开工，除非注明「可并行」。
