## §1 ★★ L1 · 参数不对（★ 占 **60%**）

**症状**：`MISSING_PARAMETER` / `INVALID_PARAMETER` / 值传了但没生效

**★ 动作（零成本，优先做）**：★ **从 interop 反射拿【真实签名】，别看文档猜**

```powershell
$asm = [Reflection.Assembly]::LoadFrom("...\SolidWorks.Interop.sldworks.dll")
$t = $asm.GetType("SolidWorks.Interop.sldworks.IModelDoc2")
$t.GetMethods() | ? { $_.Name -like "*Create*" } |
  % { "{0}({1})" -f $_.Name, (($_.GetParameters()|%{"$($_.ParameterType.Name) $($_.Name)"}) -join ", ") }
```

**★★★ 关键（★ 逐字）**：

> `Ref`/`out` 参数、参数顺序、可选参数的默认值，
> **文档经常不全，签名不会骗人**。

**★ 与本仓铁律 4 的关系**：★ 本仓写的是「**签名三源互证，冲突以出厂类型库为准**」——
★ 这份给了**具体怎么拿**（★ 反射代码）。
