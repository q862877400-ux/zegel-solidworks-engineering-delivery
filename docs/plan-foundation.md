## 一、地基阶段（4 件，不产出新工具）

### 地基 ① 口径统一：每个数字只有一个定义，且**一条命令能重算**
```
要做的：
  · 建 `docs/metrics.md`（**生成物**）—— 把项目里所有对外引用的数字，逐条写明
      「定义 / 口径 / 重算命令 / 当前值」

```

  · 生成物里同时给两个数，**永远并列出现**：
      「静态缝合覆盖」= 名字层面被包进函数的成员比例

验收：重算命令能同时吐出两个数；且台账/报告里**找不到**单独出现的"覆盖"二字
成本：约 40 分钟（依赖地基 ①）
