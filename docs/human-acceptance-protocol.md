# 四步人工验收协议（Human Acceptance Protocol）

**来源**：业主 2026-10-26 指令 ——

> 很多操作你还是做一遍给我看，然后我人工确认一下吧，免得你机器判据问题，
> 你以为验收了实际上不对。… 1. 先说你要做什么，并给出计划；2. 准备阶段：描述初始状态…
> 3. 执行阶段：开始执行…；4. 结果确认：说明现在…让我去看看是不是。

## 为什么需要（这条协议补的是**判据的盲区**）

本项目已经把「机器判据」做得相当细（61 道门禁、E1–E7 采集器/判定器、阴性对照）。
但机器判据有一个结构性的盲区：**它只能判它被写成去判的那件事**。

实录（都发生在同类问题上）：

| 曾经「机器说通过」 | 实际 |
|---|---|
| `add_component` 返回成功 | 组件在 **30 米**外（单位错，事实 570） |
| `CreateMate` 之后 `mates` 非空 | 那是 `MateGroup` **文件夹**，不是配合（第 44 轮） |
| `setattr(data,"EntitiesToMate",...)` 返回 True | 回读是 **0 个实体**（事实 566） |
| 两束射线各选中 1 个面 | 两个面**属于同一个组件** ⇒ 配合成了「面和它自己」（事实 571） |

⇒ 这四次都是「机器判据绿灯、事实是错的」。
  **人工看一眼**能一次性排除全部四类。

## 协议（四个阶段，**阶段之间必须停顿等人**）

### 阶段 1 · 计划

说明：**要做什么功能 · 怎么判定成功 · 分几步**。
不许省掉「怎么判定」—— 否则阶段 4 的确认没有靶子。

### 阶段 2 · 准备（等人确认）

★★★ **描述场景必须由工具生成，不许我手推坐标。**
   跑 `python -B tools/sw_scene_report.py --prefix <名> --grid`，它会：
   - 给各组件上色（蓝/粉/绿/橙）
   - 拍**前视/上视/右视**三张图
   - 由包围盒**自动生成**人话描述，并明确指出「这是高/矮」还是「只是前后/左右」

   ★ 为什么定这条规矩（2026-10-26 实录）：
     我把 `add_component(z_m=0.050)` 说成「抬高 50mm」，而 **SolidWorks 前视沿 −Z 看**，
     竖直方向是 **Y** ⇒ 那块板只是被推到了**后面**，前视图里两块**一样高**。
     业主一眼看出，我却"看"不出来 —— 因为我是在**脑补坐标**，不是在描述观测。
     轴语义见事实 579 与 `scripts/sw_scene.py` 的 `AXIS_SCREEN`（有 14 条测试钉住）。


- 把场景摆成**可观察的初始状态**，**保持文档打开**、窗口置前
- 用业主能核对的语言描述**他现在应该看到什么**（几个件、什么位置关系、特征树长什么样、
  哪个文件夹应该是空的）
- 同时给出**机器读数**（平移量、组件数、配合数），让两边能对照
- ★ **停下来等人说「对」**。业主说「不是这样」⇒ 该阶段失败，先查清为什么，
  不许直接进阶段 3

### 阶段 3 · 执行

真正做那件事。执行期间：

- 截图/连拍（`tools/sw_screenshot.py`、`tools/sw_snapshot_loop.py`）留过程证据
- 记录**机器读数**（读数要看**独立量**：变换矩阵、条数、哈希 —— 不是返回值）

### 阶段 4 · 结果确认（等人确认）

- 说明**现在应该是什么样**，越具体越好（哪个件移动了多少、哪个面贴住了哪个面、
  特征树里应该多出什么名字）
- 给出**执行前后的机器读数对照**
- ★ **停下来等人说「确实」**。业主说「没有/不对」⇒ 这项功能**不算通过**，
  哪怕机器判据全绿

## 硬规矩

1. **判据绿 ≠ 人工验收过**。两者都要，缺一不算。
2. **人工验收结论要记录**：写进 `specs/350-first-part-delivery/s3-acceptance.md`
   的对应条目（业主原话 + 日期 + 他确认的是什么）。
3. **不许替业主说「他确认了」**。他没答就是没答，报告里写「待人工确认」。
4. 一个功能**只做一次**四步；同一功能重复做要说明为什么（例如改了执行方式）。

## 工具

| 用途 | 命令 |
|---|---|
| 准备场景（配合演示） | `python -B tools/coop_step2_prepare_mate.py` |
| 执行（配合演示） | `python -B tools/coop_step3_execute_mate.py` |
| 截图 | `python -B tools/sw_screenshot.py --out output/shots/<名>.png` |
| 连拍（录过程） | `python -B tools/sw_snapshot_loop.py --seconds 180 --interval 3` |

★ 跑这些脚本时**先停弹窗监控**（`Stop-Process` 掉 `output/dialog-watch/watcher.pid`），
  跑完再 `python -B tools/sw_dialog_watch.py --ensure`。
  原因：监控自己会连 COM，两个客户端会互踢（事实 569）。
