## 一 · 口径（★ 先说清量的是什么，否则数字没有意义）

**口径 = 能操作 SolidWorks 的「功能」数** —— 不是工具名数，也不是 API 成员数。

清单共 **145** 项，按 SOLIDWORKS 用户的 CommandManager 心智模型组织
（画直线 / 画圆 / 拉伸 / 切除 / 拔模…这种粒度），分 11 个域。

⚠ **本表只量第一列**。三列要分开看，**不可互相替代**：

| 列 | 问的是 | 本表有吗 |
|---|---|---|
| ① **有入口** | 有没有这么个工具/名字 | ★ **本表量的是这个** |
| ② **能建成** | 真跑一次，特征树真的长了吗 | ❌ 见 §五 |
| ③ **真机验过** | 有没有留下我们自己的运行证据 | ❌ 见 `capabilities.yaml` 的 `level` |

★ 这与 `docs/metrics.md` 的纪律②一致：「任何『覆盖广 / 全覆盖』的说法，**必须带那个真机数**」。
