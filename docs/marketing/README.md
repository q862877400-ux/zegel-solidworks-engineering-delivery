## 一句话结论

**这个赛道不缺「能画」的演示，缺「画得对不对」的证据。** 别去抢「更炫的建模」，去占「唯一能拿机器判合格」这个位置。

## 三条硬数据（全来自本机实测或一手页面）

1. **B站 60 秒以内是最差区间**：≤60s 中位播放 782（n=26），1–3min 中位 5,563（n=73）。
2. **标题要质疑式，不要背书式**：挑衅质疑式中位 48,425，身份背书式中位 3,687。
3. **我们有别人没有的东西**：E1–E7 判据器 + 18 个真实坏样件，本机真跑 28 条检查 → pass 7 / fail 18 / unknown 3。

## v3 修正（YouTube 20 频道实测，2026-11-04）

**一条结论直接改了主片结构**：YouTube 播放第一的那条（Hestus，**75 个订阅 / 1,859 万播放 / 101 秒**）标题是全表最弱的纯产品名，赢在屏幕上并排两个数字——`01:44` vs `00:04` 的时间对比条。封面做得最漂亮的那条（CADbyAI，`TEXT → CAD` + `NO MACROS`）只有 **1,758** 播放。

⇒ **播放跟「证据形态」有关，跟文案无关。** 主片因此加了「判定对照条」：左边 AI 生成 `00:24`、右边判据跑 `00:03`，同一个视觉位置换我们的语义。

其余三条新结论：新质疑「**dumb solids / STEP 是死实体**」（HN 一手，主片加 18 秒特征树反驳段）· 竞品 2026-10-29 被曝**后台扫描上传用户的 CAD 文件**（新增独立 60 秒片）· 中文 SolidWorks+AI 在 YouTube **最高只有 3,185 播放**，主战场在 B站。
