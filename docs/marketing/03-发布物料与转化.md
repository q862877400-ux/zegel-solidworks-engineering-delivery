## 四 转化：四层钩子

| 层 | 钩子 | 门槛 | 用户动作 | 我们交付 |
|---|---|---|---|---|
| **L1 轻** | 判据清单（一页纸 PDF + 18 个坏样件名） | 评论「判据」 | 留一条评论 | 自动回复 + 私信发文件 |
| **L2 中** | 坏样件 JSON + 判据运行脚本（自己能跑） | 私信报「我做了 XX」 | 说一句自己的场景 | 发 GitHub Gist / 网盘 |
| **L3 重** | 首件走查（拿他的一个真实零件跑一遍七道判据） | 提供模型 + 用途 | 发模型 | 出报告，公开或不公开由他决定 |
| **L4 长期** | 规则包 + 判据更新（社群） | 走过 L2 或 L3 | 订阅 | 持续更新 |

**L3 是真正的转化点**，也是唯一能验证「这东西到底有没有用」的路径。前 20 个 L3 案例比前 20 万播放值钱。

### 商业化口径（照行业已跑通的形态，不自己发明）

已核实的同赛道变现结构（见 [01](01-竞品宣发拆解.md) §2.1b）：

- **卖的是「规则包/源码包 + 社群会员」，不是接单。**
- 价格锚点：社群年费 **50 元/年量级** 是这条线的历史起点（2017 年一手公告），当前主流知识星球 **399 元/年** 是另一档。
- **接单不值得做**：作业单 10–100 元、兴趣定制 60–1,250 元的红海，且验收标准极低（「能交作业就行」），跟我们的判据定位正好相反。
- **第二条收入**：工具邀请返利（同赛道账号在教程里挂工具邀请链接）。我们若有合作方，同理。

> ⚠️ 一条判断：**不要学「标题挂源代码」那种做法**。它把产品降级成「预写包 + 一句话触发」，恰好坐实「套壳 RPA」的质疑。我们的 L4 卖的是**判据与验收能力**，不是源码包。

**私信自动回复模板**：

```
判据清单发你了 → [链接]
两件事想问你：
1. 你现在画东西，最花时间的是哪一步？（草图约束 / 改型 / 出图 / 装配干涉排查）
2. 有没有一个你想验证的零件？发我模型，我拿七道判据跑一遍给你看，不收费。
```

## 六 数据追踪（发布后看什么，不看什么）

### 6.1 不看播放量

播放量受推荐流随机性影响，对技术内容几乎没有判断力。**看这三个：**

| 指标 | 为什么看它 | 参考基准 |
|---|---|---|
| **投币/播放** | 技术内容里，投币是「有用」的信号，比点赞强得多 | 同赛道爆款实测：7,740 / 289,170 = **2.68%** |
| **评论里「判据」条数** | 真实需求信号，直接对应 L1 转化 | 首月 > 30 条算通过 |
| **L3 走查申请数** | 唯一能验证产品是否有用的指标 | 首月 > 3 个算通过 |

### 6.2 发布后 72 小时的三次读数

| 时点 | 记什么 | 决定什么 |
|---|---|---|
| +6h | 前 6 小时播放 / 点击率（有后台才看得到） | 封面要不要换 |
| +24h | 投币比、评论关键词 | 标题要不要改（B站可改一次） |
| +72h | 完播率、L1 转化条数 | 这条值不值得做续集 |
