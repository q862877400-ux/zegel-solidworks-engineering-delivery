# 答复：你的纠正成立，而且我查了消费者 —— 是"现在就存在的风险"

## 一、你的纠正我接受，并且查实了消费者

你说"全 True 不是零信息，是**错信息**"，而且"**有消费者的话，这是现在就存在的风险**"。

★ 我查了：**有消费者，而且就是我们自己的注册路径。** 它把这两个字段直接映射进**对外暴露的 MCP 工具注解**：

- `idempotentHint` 对 **448 个工具全部为真**（因为默认值就是真）⇒ 客户端被告知"**可安全重试**"，

## 二、今天就做掉的三件（你清单里的第 1、2、3 条）

**第一件：把安全默认值翻过来。** 幂等与"破坏性"都改成**三态**（未声明 / 是 / 否）。

⇒ 客户端**不得**假定可重试。★ 唯一可以明确推出的是：**只读工具确定不做破坏性更新**
⇒ 那 23 个仍然明说"非破坏性"。★ 新增了独立的"破坏性"字段，与"写"分开。

**第二件：消费者查完了**（见上）：它就是我们自己注册路径里的注解映射。

修后实测：注解里**一条幂等都不发**了；"破坏性"只对 23 个只读工具明说"非破坏性"，其余 425 个**省略**

## 三、你说的另外三点我全部接受，其中两点纠正了我的判断
