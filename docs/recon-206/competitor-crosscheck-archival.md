## 一 · ★★ 怎么用（★ 这是本件的核心）

**在「从四家外部项目抄一个 API 调用」之前，先来这一步** —— 它接在既有的取材顺序里：

```
★ 规格 206 的「写码前必查」链：
   ① 官方页（签名 + Remarks）

```
★ **第 ③ 步要问的问题只有一个**：
> ★★ **「我要抄的这个调用形状，在四家里出现过吗？它在我们核过的三个源里查得到吗？」**

> ★★ 那可能正是**别家也写错了**（★ 而这类错**照抄就跟着错**）✓

## 四 · ★ 它的**限度**（★ 同样要带走）

- ★ **不是**一份"四家谁对谁错"的排名表 —— ★ 它只说「核过的三源里查不到」；
