## 三 · ★ 本汇总不算什么（限度，必读）

1. **deep 档未收齐** ⇒ 上表「反方向实测样本」只是**部分值**，不是定案。
2. **一条真机都没验** —— 全程离线静态（D-3：几十个 bunny 并发抢单实例 COM 会**死锁**）⇒
   所有「后端可达」都是**静态推断**。
3. **「照官方签名写就能成」未被证明** —— 先例：`FeatureFillet3` 盒子边成、放样体**静默失败**（事实 556）
   ⇒ 每件活落地必须配**负例**。
4. **分类器的全量假阳性率仍未被独立验证** —— 本规格测的是「它标『已有』时的错判率」，
   不是「它标『缺口』时的漏判率」；后者只有 deep 档的部分样本。
5. ★★ **`verdict` 这个词表本身有一处边界含混**（第 23 轮的小样本观察，**n 很小、只作限定**）：
   拿**已付过钱的** DeepSeek 那批（`output/bunny-records/`，**不进交付物**）与 bunny 的记录
   做交叉核对，同 op 者 **8 条**：
   · `annotation` / `auto_center_marks` / `balloon` ⇒ 两边都判「**已有等价物**」⇒ **一致** ✓
   · `batch_execute_macros` / `batch_run_macros` ⇒ bunny「**其实没有**」· DeepSeek「已有等价物」⇒ **分歧**
   · `batch_process_files` ⇒ bunny「**查不到**」· DeepSeek「已有等价物」⇒ **分歧**
   ⇒ ★★ 分歧**全部集中在"批量宏"一族**，而**两边都没说错**：DeepSeek 指的是
     「**有等价物**」（`solidworks_macro_run` 循环调用即可），bunny 指的是「**没有专用工具**」✓
   ⇒ ★ **"已有等价物" 与 "其实没有（但不必做）" 可以描述同一件事的两面** ⇒
     ★★ **读那两组计数（23 / 17）时必须知道这条边界**，别把它当成纯技术判断 ✓
   ⚠ **本条的两个限度**：① **n=8**，只是观察不是结论；② 两个生产者**用的 schema 不同**
     （DeepSeek 那批 `recommendation` 恒为 `None`）⇒ ★ 只有 `verdict` 可比，`recommendation` **不可比** ✓
