## 三、发现的问题

### 3.1 ❌ 完全没有配合（最严重）

8 个组件全部 `fixed=true`。也就是说**它们只是按 transform 摆好的散件**：

- 移动任何一个都不会带动其它零件
- 不能做运动分析 / 装配干涉检查 / 参数化更新
- 各零件的坐标是手填的，不是配合算出来的

**BT30 ATC 换刀主轴至少应该有这些配合：**
| 配合 | 关系 |
|---|---|
| 主轴 ↔ 壳体 | 同轴（锥孔配合） |
| 刀柄 ↔ 主轴 | **锥面配合**（BT30 的 7:24 锥角，这是 ATC 的核心） |
| 拉钉 ↔ 壳体/主轴 | 同轴 + 螺纹或销 |
| 碟簧 ×4 ↔ 主轴/壳体 | 同轴 |
| 扳手 ↔ 拉钉 | 同轴 |
| 标准件（螺母/螺钉/垫圈）| 螺纹/销配合 |

### 3.2 ❌ 缺主轴本体

**BT30 ATC 换刀主轴的核心零件是「主轴」**（带 BT30 内锥孔的旋转轴体）。
现在装配里只有：壳体、刀柄、拉钉、4×碟簧、扳手 —— **没有主轴**。

套装总质量 3.26 kg 偏轻，缺的主轴本体通常约 1.5–2 kg。

### 3.3 ⚠ 3 个标准件未插入

STEP 已生成并通过双内核验证（偏差 0.001%–0.003%），但**没进装配**：

| 文件 | 规格 |
|---|---|
| `六角螺母_M12_ISO4032.step` | M12 |
| `内六角螺钉_M12x40_ISO4762.step` | M12×40 |
| `平垫圈_M12_ISO7089.step` | M12 |

（这三个通常是 BT30 拉钉/壳体的紧固件，取决于具体设计）
