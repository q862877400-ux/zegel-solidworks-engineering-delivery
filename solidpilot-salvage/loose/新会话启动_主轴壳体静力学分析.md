## 5. 官方指导（已查证，勿凭常识）

**薄壁件的关键**（`C:\swdoc\sim_cworks\c_Modeling_Shell_Problems.htm`）：

> *"When you create a study, the program **automatically determines the mesh type** to be solid,
> shell, or mixed based on the existing geometry... **Solid Parts**"* —
> 实体零件默认用**实体网格**；*"You also have the option to first treat sheet metals as solid
> bodies, and then **convert manually selected solid faces to shells**."*

⇒ 本零件是拉伸/切除的**实体**（不是钣金），**默认走实体网格**。
壳体薄壁 ⇒ **建议手动把面转成壳单元**（网格更快、结果更准）。

**夹具操作**（`C:\swdoc\sim_cwbasics\t_Adding_Fixtures_Restraints.htm`）：
> 右键 Fixtures → Fixed Geometry → 选面 → ✓

**网格尺寸**：薄壁筒的关键参数。太小=算很久，**环向至少 3~4 个单元**，太大=应力不准。

## 6. 执行步骤（建议顺序）

1. **确认 SolidWorks 已开**，零件已打开
2. **检查 `固定-1` 固定的是哪个面** —— 主轴壳体是**筒**，应该固定**一端端面**（或用轴承配合面）。若固定错了面，删掉重建
3. **加载荷**：右键 `外部载荷` → 压力/力/轴承力。轴承载荷建议用 **轴承力（Radial/Fixed）**，或简化为端面压力
4. **网格**：右键 `网格` → 先考虑转壳单元（选项卡里选面），再设置单元尺寸
5. **求解**：右键 `静力学分析 2` → **运行**（会弹模态框，**要等**）
6. **读结果**（这是最终要的）：
   - **最大 von Mises 应力**（与材料屈服强度比 → 安全系数）
   - **最大位移**（mm）
   - 6063-T6 屈服强度约 **240 MPa**（顺变形极限 145 MPa）—— 算安全系数用它

## 7. 结果怎么汇报

给用户这四个数 + 判断：
- 最大等效应力（MPa）及其位置
- 最大位移（mm）及其位置
- **安全系数 = 240 / 最大应力**
- 一句话结论：壁厚够不够、要不要加筋/加厚

⚠ 注意：`AI操作手册_SolidWorks.md` 里记录的 240MPa 是常用值，
**以 SolidWorks 材料库里 6063-T6 的实际屈服值为准**（右键材料 → 属性里能看到）。
