## 结论

- 在此载荷工况下壳体**强度极富余**，安全系数约 **137**，远大于 2 的常规要求。
- 最大位移仅 0.37 µm，相对 110 mm 长度可忽略（≈ 3e-6 相对变形），刚度同样不是问题。
- **壁厚完全够用，不需要加筋或加厚。**

## ⚠️ 工况说明与限制（重要）

本次载荷是「力作用在圆柱内孔面上、方向为**法向**」，SolidWorks 沿整圈内孔把 10 kN 分布成径向载荷，
净合力为零，**等效于内压作用**，因此只产生环向应力、没有弯矩。

真实轴承载荷是**局部**的（一般只覆盖 90°~120° 圆周），会在固定端附近产生**弯曲应力**，
其量级通常比均匀内压高一个数量级。所以：

- 上面 FoS≈137 应视为**上界（偏乐观）**，不是轴承工况的真实安全系数。
- 由于 `轴承载荷` 功能要求同时选择「坐标系 + 同半径圆柱面」且坐标系 Z 轴与柱面轴线重合，
  本零件缺少可直接选取的坐标系，该路径未能自动化完成，故退化为法向力（启动包允许的「简化」路线）。
- 若要做真实轴承工况评估：把 10 kN 改为**单侧/局部**分布（例如只在内孔下半圈或一侧 90° 范围施加载荷），
  或补建坐标系后改用 `轴承载荷(Radial/Fixed)` 重新求解。
- 应力与载荷近似线性，10 kN → 20 kN 应力约翻倍；若要按真实切削力（可达数 kN~十几 kN）评估可直接缩放。

## 复现步骤（本次实际走通）

1. Simulation 选项卡 → `新算例` → 名称 `静力学分析 2`、常规模拟=静力学分析 → ✓
2. 研究树 `夹具` 右键 → `固定几何体(G)...` → 选顶端环形端面 → ✓  （得到 `固定-1`）
3. 研究树 `外部载荷` 右键 → `力(F)...` → 选内孔圆柱面 → 值 `10000` N，方向=法向 → ✓ （得到 `力-1`）
4. 研究树零部件 `主轴壳体_Housing` 右键 → `应用/编辑材料(M)...` → 选 `AISI 1020` → `应用(A)` → `关闭(C)`
   ⚠️ **必须先设材料再跑**，否则报「材料不适用于下列几何体」
5. 研究树 `网格` 右键 → `生成网格(R)...` → 密度「良好」→ ✓
6. 研究树 `静力学分析 2` 右键 → `运行(R)`
7. 双击 `应力1 (-vonMises-)` / `位移1 (-合位移-)` 读图例

## 环境备注（本机 automation 的坑，供后续参考）

- 屏幕真实分辨率 **2560×1440**；CUA `get_desktop_state` 返回 2048×1152（等比裁切），
  `get_window_state` 预览上限 1568 px，**不能把预览像素直接当屏幕坐标用**。
- CUA 驱动的 window-local → screen 换算会带一个漂移偏移；最终改用
  `D:\AI\sw_ui.ps1` 里的 Win32/UIA 原语（见下）才稳定。
- SolidWorks 的按钮是 `CCPushButton` / 报成 `ControlType=Pane`，
  所以按 `ControlType=Button` 搜索会返回 0 个；改用 **句柄 + BM_CLICK** 才点得动。
- 本机 **只有鼠标输入能到达 SolidWorks，键盘输入无效**（SendInput 的按键不生效），无法用快捷键。
- 同机有另一个 DSH 会话在跑，`Get-Process .MainWindowHandle` 会漂移指向别的窗口
  （曾返回 0x8656420），必须钉死 SolidWorks 主窗口句柄 **0x770C14**。
- `AttachThreadInput` 借前台会被另一个会话的高权限终端秒抢回去；
  实测有效做法是「钉住句柄 → 强制前台 → 立刻 SendInput 鼠标」，全在一次 PowerShell 调用里完成。
