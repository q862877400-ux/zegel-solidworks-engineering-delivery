> **本篇是推翻我此前 15 轮做法的关键文档。** 全部内容来自本机官方 CHM：
> `D:\Program Files\SOLIDWORKS Corp\SOLIDWORKS\lang\english\otsimtopology.chm`
> 解包到 `C:\topo_en\`（11 个 .htm）。**不是网上搜的。**

## 0. 怎么读本机官方 CHM（踩过的坑）

```powershell
# ① 输出目录必须【不存在】，且路径【越短越好、不能有空格】
#    我先用 "$env:TEMP\...\官方文档\..." 嵌套路径 → 静默失败（0 个文件）
#    改成 C:\topo_en 立刻成功（64 个文件）
$tmp = "$env:TEMP\otsimtopology_en.chm"
Copy-Item "D:\...\SOLIDWORKS\lang\english\otsimtopology.chm" $tmp -Force
$o = "C:\topo_en"; if(Test-Path $o){ Remove-Item $o -Recurse -Force }
Start-Process hh.exe -ArgumentList "-decompile",$o,$tmp -Wait -NoNewWindow

# ② 中文 CHM 用 Get-Content -Raw 读会乱码（GBK），加 -Encoding UTF8 或用英文版
```

⚠ **官网已不可靠**：`help.solidworks.com` 本机 `Invoke-WebRequest` 能 200，但**页面是 Next.js
单页应用，HTML 里没有正文**（只有 "Loading JS..."）；`web_fetch` 出口 IP 被 403；`r.jina.ai`
本轮已要 key（401）。**⇒ 官方 CHM 才是可靠源**，本机有中英各 100 个（各约 204 MB）。

## 1. ⚡ 最重要的一条

> **"During optimization, the software always preserves the faces to which you apply
> fixtures and loads."**（施加夹具和载荷的面会被自动保留）

⇒ **`Preserved Region` 是额外的**，不是必需的。我此前把它当成"必须手工锁住轴承位"，
方向错了。

## 2. 官方完整流程（以官方"刹车盘拓扑优化"教程为例）

| 步骤 | 官方操作 | 关键 |
|---|---|---|
| 1 | `New Study` → `Topology Study` | — |
| 2 | **目标与约束**：研究树 `Goals and Constraints` → `Best Stiffness to Weight ratio (default)` | **质量约束是这个节点的默认约束**，不是单独建 |
| | └ `Mass Constraint (Default)` → `Reduce mass by (percentage)` = **75** | 语义是"**减重百分比**"，不是我用的 `SetValue(50)` |
| | └ `Stress / Factor of Safety Constraint` → `Specified factor` = **80** | 官方还加了**应力/安全系数约束** |
| 3 | **夹具**：`Fixtures` → `Fixed Geometry` → 从**选择集**取面 | 依赖**预建选择集** |
| 4 | **外载**：`External Loads` → `Torque`（力矩 700 Nm）| 从选择集取面 + 从圆柱面取**方向轴** |
| 5 | **制造控制**：`Manufacturing Controls` → `Add Preserved Region` → 再从选择集取面 | 额外保留半径 |
| 6 | 网格 → 运行 → 查看/导出结果 | — |

## 3. 与我此前做法的根本差异

| | 官方 | 我此前（错） | 后果 |
|---|---|---|---|
| 质量约束 | 研究树 `Goals and Constraints` 下的**默认约束**，"减重百分比" | `TopologyStudyManager.CreateMassConstraint` + `SetMassPreference/SetValue` | **走错 API 层级，约束大概率没落到研究上** |
| 几何选取 | **预先建 Selection Sets**（`fixtures`/`load`/`load direction`），再从选择集取 | 运行时现选面（`SelectByID2`） | 官方流程根本不依赖运行时拾取 |
| 保留区 | 额外项 | 当成必需项 | 方向性错误 |
| 应力约束 | 官方有（Specified factor=80）| 完全没有 | 缺一项关键约束 |

⚠ **我此前 11 种 `AddRestraint` 调用形态全部失败的根因，很可能就是【没有预建选择集】**——
官方的 `Fixed Geometry` 是从选择集拿面，而不是让我传一个面数组。
