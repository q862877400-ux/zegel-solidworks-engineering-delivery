## ⚑⚑ 本轮第一件事是更正我自己的一个错
上一轮我说「**ITableAnnotation 上没有读写单元格文本的东西**」，
并据此删掉了 `get_table_cell_text` / `set_table_cell_text`。

**那是错的。** 反射实测该接口有**属性形态**的单元格文本访问：

    String get_Text(Int32, Int32)             ← 2 参（行, 列）
    String get_Text2(Int32, Int32, Boolean)   ← 3 参（行, 列, 布尔）
    String get_DisplayedText(Int32, Int32)
    String get_DisplayedText2(Int32, Int32, Boolean)

缺的只是**方法形态**（`GetText` / `SetText`）。我初稿只搜了
`Get`/`Set` 大写开头的**方法**形态，没搜 `get_`/`set_` 的**属性**形态，
于是误判为整段功能不存在。

⇒ 这是**第 8 次凭印象判断成员**，方向与前七次相反：前几次是**多写**，
这次是**删多了**。教训写进代码与测试注释：
**否定一个成员存在之前，要把两种形态都搜过。**

已恢复 `get_table_cell_text` / `get_table_cell_text2`（走属性形态 + arity 护栏），
写侧仍不提供（两种形态都确实没有 Set）。测试同步改写。
