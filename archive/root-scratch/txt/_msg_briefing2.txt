外部审阅简报 · 去文件名版（高级 AI 读不到我们的文件）

★ 用户指出：高级 AI 只能读**粘贴过去的正文**，读不到本项目任何文件 ⇒ 简报里凡出现文件名/目录名/路径
对读者都是噪音，且会让文档显得"假设他能访问仓库"。

改了什么
· 全文**零文件名、零目录名、零路径**（机器验过：`.md/.py/.yaml/.yml/.json/.ps1`、盘符、各层目录名、
  常驻指令名、长程计划名、能力清单名、门禁脚本名、进度字段名 —— 匹配 **0 处**）
· 保留的反引号内容经复核**全是概念而非文件**：SolidWorks API 成员名（`AccessSelections` /
  `PostIntersect` / `RecordLine` / `Select4` / `SelectByID2` / `SetFixedFace` / `SetSelectedObjectMark`）、
  语言字面量（`None` / `True` / `false`）、模式名（`lean` / `mode`）、以及**我们自己的验证等级取值**
  （`verified` / `stitched` / `source_verified` / `indexed` / `not_implemented` —— 都在 §3/§11 里有定义）
· 所有"想知道 X 去哪看"的指路，改成**"用什么字段/什么机制"**（例：能力清单 → "能力清单里的验证等级字段"；
  长程计划 → "长程计划里的当前游标字段"；生成物 → "生成物（可重跑）"）
· §12 从"去哪看"改成 **「本简报的证据强度」** —— 因为你读不到文件，所以按**证据强度分级**
  （刚实测过 / 取自产物未复跑 / 我的判断未经确认 / 明确没做到）★ 这是对"读不到文件"最诚实的补偿
· §0 开头加一行显式声明：**你看不到本项目的任何文件，本文不引用任何文件名或路径**

★ 自足性检查：一个完全没读过本项目的人，只拿这份正文，能看懂每一节在说什么
（每条事实都自带"它是什么、有多少条"，不依赖任何外部查找）。
